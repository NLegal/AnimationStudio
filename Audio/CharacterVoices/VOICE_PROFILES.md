# Character Voice Profiles

> **Version:** 1.0
> **Total Characters:** 39 (38 + 1 bonus)
> **Universe:** AI Nursery Rhyme Studio — Little Learning Town
> **Philosophy:** Consistent voices build brand recognition. Children recognize audio before visuals.

---

## Voice Profile Template Reference

Each entry includes:
- **Age Range** — child/adult/elderly
- **Pitch** — low, medium-low, medium, medium-high, high
- **Energy** — calm, moderate, energetic, very energetic
- **Speech Speed** — slow, medium, fast (relative to preschool content)
- **Accent** — neutral, regional, none
- **Voice Quality** — warm, bright, soft, raspy, clear, etc.
- **Laugh Style** — giggle, chuckle, snort, silent laugh, etc.
- **Singing Style** — bright, soft, enthusiastic, gentle, etc.
- **Catchphrases** — from character bios
- **TTS Model** — Kokoro, XTTS v2, or Piper
- **Voice Reference Notes** — how to describe in prompts
- **Unique Vocal Characteristics** — child-friendly distinctions
