# Sound Effects Library Index

## Version 1.0

---

## Introduction

Reusable sound effects create a consistent audio identity. When a door sounds the same in episode 1 and episode 100, children learn to recognize the world. This library catalogs every sound effect needed for production, organized by category with clear naming conventions.

Each sound effect should be recorded or sourced at 48 kHz / 24-bit stereo, edited to remove noise, and archived with descriptive metadata.

**Naming Convention:** `SFX_Category_###`

**Example:** `SFX_Footstep_001.wav`

---

## Naming Rules

- Category is PascalCase
- Numbers are zero-padded to three digits
- File extension: .wav (archival), .mp3 320kbps (delivery)
- Metadata tags: AssetID, Description, Duration, Category

## Production Notes

### Recording Standards
- Sample rate: 48 kHz
- Bit depth: 24-bit
- Channels: Stereo (mono acceptable for spot effects)
- Format: .wav for archival, .mp3 320kbps for delivery

### File Organization
```
SFX/
  Footstep/
  Door/
  Toy/
  Nature/
  Human/
  Magic/
```

### Volume Guidelines
- Spot effects (footsteps, door knocks, etc.): -6dB to -12dB relative to dialogue
- Background effects (ambient birds, wind): -18dB to -24dB
- Impact effects (blocks, drums): -3dB to -6dB
- Never exceed -3dB peak
