# Music Style Guide — Little Learning Town

## Musical Identity

Little Learning Town music is cheerful, bright, educational, and simple. Every song should feel like it belongs to the same world — a place where learning is fun, melodies are memorable, and production is warm and clean.

### Core Principles

- **Melody-first**: Simple, singable melodies that children can repeat after one listen
- **Repetition with purpose**: Choruses repeat 3–4 times; educational content repeats for reinforcement
- **Positive affect**: Major keys, bright timbres, never minor or dissonant
- **Age-appropriate complexity**: Preschoolers process simple rhythms and narrow pitch ranges
- **Production transparency**: Vocals always clear, lyrics intelligible, no masking

---

## Tempo

### Overall Range: 80–130 BPM

| Category | Tempo Range | Rationale |
|----------|-------------|-----------|
| Lullabies / Bedtime | 60–80 BPM | Slow, soothing, sleep-inducing |
| Educational (alphabet, counting, shapes, colors) | 90–110 BPM | Moderate pace for learning, room for repetition |
| Action / Exercise | 100–120 BPM | Energetic but controlled |
| Upbeat / Dance | 110–130 BPM | High energy for active play |
| Holiday / Birthday | 100–120 BPM | Celebratory but not frenetic |
| Interactive / Call-and-response | 90–110 BPM | Space for child participation |
| Nursery rhymes | 80–110 BPM | Traditional pace, flexible |

---

## Key Signatures

### Preferred Keys (bright, simple)

| Key | Why |
|-----|-----|
| **C major** | Brightest, no sharps/flats, easiest for children to sing |
| **G major** | Warm and bright, one sharp (F#), very common |
| **F major** | Gentle warmth, one flat (Bb), good for lower children's voices |
| **D major** | Bright, two sharps, good for energetic songs |

### Avoided Keys

Keys with 3+ accidentals (E major, Ab major, etc.) — they sound less bright and are harder for young children to sing.

---

## Chord Progressions

| Progression | Feel | Usage |
|-------------|------|-------|
| **I–IV–V–I** (C–F–G–C) | Classic, resolved | Core progression for most songs |
| **I–V–vi–IV** (C–G–Am–F) | Emotional, pop | Verses, choruses with gentle emotion |
| **I–vi–IV–V** (C–Am–F–G) | Doo-wop, classic | Catchy, memorable choruses |
| **I–IV–I–V** (C–F–C–G) | Simple, repetitive | Alphabet songs, counting songs |
| **vi–IV–I–V** (Am–F–C–G) | Modern pop | Upbeat dance songs |

All progressions stay diatonic (no borrowed chords, no chromaticism) for preschool accessibility.

## Instrumentation Guide

### Core Instruments (always available)

| Instrument | Role | Character |
|------------|------|-----------|
| **Piano** (acoustic) | Harmony, melody, rhythm foundation | Warm, bright, versatile |
| **Acoustic guitar** | Rhythm, strumming patterns | Folk, friendly, organic |
| **Xylophone / Glockenspiel** | Melody accents, educational sounds | Playful, colorful, child-like |
| **Hand drums** (bongos, djembe, shakers) | Rhythm section | Organic, bouncy, fun |

### Accent Instruments (use selectively)

| Instrument | Effect |
|------------|--------|
| **Bells** (sleigh bells, handbells) | Celebration, magic, transitions |
| **Tambourine** | Energy boost on choruses |
| **Triangle** | Accent hits, educational cues |
| **Recorder** | Simple melodies, school setting |
| **Ukulele** | Light, cheerful, tropical feel |
| **Claves / Wood block** | Rhythmic pattern, counting songs |
| **Marimba** | Warm alternative to xylophone |
| **Kazoo** | Silly, fun, child participation |

### Avoid or Use Sparingly

| Instrument | Reason |
|------------|--------|
| Heavy electric guitar | Too aggressive for preschool |
| Distorted bass | Harsh, overwhelming |
| Synthesizer pads (unless gentle) | Can sound cold, artificial |
| Heavy sub-bass | Inaudible on small speakers, fatiguing |
| Complex drum kits | Too busy; stick to kick/snare/hi-hat |
| Orchestral strings (full) | Too dramatic; use pizzicato or solo sparingly |

## Arrangement Style

### Simple Layers

```
Layer 1:  Rhythm (drums, percussion)
Layer 2:  Harmony (piano, guitar)
Layer 3:  Melody (vocals, xylophone)
Layer 4:  Accents (bells, tambourine, effects)
```

Each layer enters and exits cleanly. Never more than 4–5 simultaneous elements.

### Clear Melody

- Melody stays in a comfortable range (C4–C5 for children's vocals)
- Stepwise motion with occasional small leaps
- Repeating phrases build familiarity
- Call-and-response patterns invite participation

### Strong Rhythm

- Steady, unambiguous downbeat
- Percussion supports the vocal rhythm
- Syncopation only when simple and predictable
- Tempo never changes mid-song

## Production Values

| Parameter | Standard |
|-----------|----------|
| **Mix balance** | Vocals -6 dB above instrumental bed |
| **EQ** | Roll off below 60 Hz; gentle cut at 300 Hz (mud); slight boost at 3-5 kHz (presence) |
| **Compression** | Light on vocals (2:1–3:1), soft knee |
| **Reverb** | Short room or plate (0.8–1.2s decay), never long hall |
| **Stereo width** | Moderate; keep center clear for vocals |
| **Loudness** | Integrated -14 LUFS (streaming standard) |
| **True peak** | No higher than -2 dBTP |
| **Noise floor** | Below -60 dB |
| **Fade in/out** | 1–2 seconds preferred |

No harsh frequencies above 8 kHz without gentle attenuation. No sudden volume changes. The mix must be safe for headphone-listening toddlers.

## Duration Standards

| Duration | Structure | Best For |
|----------|-----------|----------|
| **30 seconds** | 1 verse + 1 chorus + 1 chorus | Short transitions, Instagram/Shorts, intro/outro tunes |
| **1 minute** | Intro + 2 verses + 2 choruses | Single-concept educational songs (letter A, number 1) |
| **2 minutes** | Full structure (intro, verse, chorus, verse, chorus, bridge, outro) | Standard episode songs |
| **3 minutes** | Full structure + extended bridge + instrumental break | Feature songs, holiday specials |
| **5 minutes** | Compilation of shorter sections | Medleys, video compilations |

Longer pieces should be assembled from shorter song blocks rather than generated as one continuous piece. This simplifies editing, remixing, and localization.
