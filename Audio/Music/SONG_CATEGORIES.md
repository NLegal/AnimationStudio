# Song Categories — Little Learning Town

## Complete Category Reference

---

### Alphabet

| Field | Value |
|-------|-------|
| **Description** | Songs teaching letter recognition, phonics, and the ABC sequence |
| **Educational purpose** | Letter names, letter sounds, alphabetical order, phonemic awareness |
| **Target age** | 2–5 years |
| **Tempo** | 100–120 BPM |
| **Instrumentation** | Piano, xylophone, hand drums, bells |
| **Lyric theme** | "A is for Apple, /a/ /a/ Apple" — each letter with an object and sound |
| **Example topics** | ABC Song (traditional), Phonics Song (letter sounds), Letter A Adventure |
| **Typical duration** | 1 min (per letter), 3 min (full alphabet) |

---

### Numbers

| Field | Value |
|-------|-------|
| **Description** | Songs teaching counting, number recognition, and basic arithmetic |
| **Educational purpose** | Counting 1–10, 1–20, number names, one-to-one correspondence, simple addition/subtraction |
| **Target age** | 2–5 years |
| **Tempo** | 100–120 BPM |
| **Instrumentation** | Piano, wood blocks (count hits), marimba, hand drums |
| **Lyric theme** | Counting objects, "5 little ducks," number formation, "1+1=2" |
| **Example topics** | 5 Little Ducks, 10 in the Bed, Counting to 20, Number Song |
| **Typical duration** | 1–2 min |
