## Opening Templates

### Template 1 — Standard Welcome
```
Scenario:       Episode beginning, standard opening
Narrator Line:  "Welcome to Little Learning Town!"
                [3s pause — wide shot establishes town]
                "Today, our friends are learning about [topic]."
Timing Notes:   2s pause before first line. 3s between lines.
                4s hold before first character speaks.
```

### Template 2 — Question Hook
```
Scenario:       Episode opening with a question to engage children
Narrator Line:  "Welcome to Little Learning Town!"
                [2s pause]
                "Do you know what [concept/question] is?"
                [3s pause — let children think]
                "Let's find out together!"
Timing Notes:   3s pause after question. 2s pause before "Let's find out".
                Question asked with rising intonation, curious tone.
```

### Template 3 — Morning / Time-of-Day
```
Scenario:       Episode that starts with a specific time of day
Narrator Line:  "Good morning! Welcome to Little Learning Town!"
                [2s pause]
                "The sun is shining and a new day of learning is beginning."
                [3s pause — morning scene establishes]
Timing Notes:   Slightly more energetic in morning episodes.
                2s pause between sentences for warm morning feel.
```

### Template 4 — Song Introduction
```
Scenario:       Episode opening with a song
Narrator Line:  "Welcome to Little Learning Town!"
                [2s pause]
                "It's time to sing! Let's all [song topic] together!"
                [2s pause — then music starts]
Timing Notes:   Energetic语调. 2s pause before music cue.
                Narrator exits before song begins.
```

### Template 5 — Seasonal / Special Episode
```
Scenario:       Holiday, birthday, or seasonal episode
Narrator Line:  "Welcome to Little Learning Town!"
                [2s pause]
                "Today is a special day! It's [occasion]!"
                [3s pause — festive scene]
                "Let's see what our friends are doing to celebrate."
Timing Notes:   Warmer, more excited tone for special episodes.
                Pause slightly longer for visual celebration.
```

## Transition Templates

### Template T1 — Location Change
```
Scenario:       Moving from one location to another
Narrator Line:  "Meanwhile, at the [location]..."
Timing Notes:   2s pause after previous scene.
                "Meanwhile" spoken with slight emphasis.
                3s pause to let new location establish.
```

### Template T2 — Time Passage
```
Scenario:       Time has passed within the episode
Narrator Line:  "Later that [time of day]..."
Timing Notes:   2s pause after previous scene. 2s pause after line.
                Tone: reflective, bridging.
```

### Template T3 — Character Introduction
```
Scenario:       New character entering the scene
Narrator Line:  "And here comes [character]!"
                [2s pause]
                "[Character] loves to [activity]."
Timing Notes:   1s pause before. 2s pause between lines.
                Bright, welcoming tone.
```

### Template T4 — New Activity
```
Scenario:       Characters moving to a new activity
Narrator Line:  "Now it's time for [activity]!"
                [2s pause]
                "Let's see what happens."
Timing Notes:   Energetic. 2s pause. 2s after.
```

### Template T5 — Problem Introduction
```
Scenario:       A problem or challenge arises
Narrator Line:  "Oh-oh! [Character] has a problem."
                [2s pause]
                "[Brief description of problem]."
                [2s pause]
                "How will [character] solve it?"
Timing Notes:   "Oh-oh!" with gentle concerned tone.
                3s pause after question for child engagement.
```

### Template T6 — Learning Moment
```
Scenario:       Transitioning into an educational segment
Narrator Line:  "Did you know..."
                [1s pause]
                "[Educational fact]?"
                [3s pause — let it land]
                "Let's learn more!"
Timing Notes:   Curious, wonder-filled tone. 3s pause after fact.
```

### Template T7 — Time of Day Shift
```
Scenario:       Moving from day to night or vice versa
Narrator Line:  "As the [sun/moon] [sets/rises]..."
                [2s pause]
                "It's time for [activity]."
Timing Notes:   Softer tone for evening. Brighter for morning.
                2s pauses throughout.
```

### Template T8 — Group Gathering
```
Scenario:       Characters coming together
Narrator Line:  "All of [character's] friends gathered together."
                [2s pause]
                "What could they be planning?"
Timing Notes:   Warm, curious tone. 3s pause after question.
                Anticipation building.
```

## Educational Explanation Templates

### Template E1 — Simple Fact
```
Scenario:       Introducing a factual concept
Narrator Line:  "Did you know that [fact]?"
                [3s pause — visual of the fact]
                "[Elaboration in one simple sentence]."
Timing Notes:   3s pause after question. 2s after elaboration.
                Curious, wonder tone.
```

### Template E2 — Concept Definition
```
Scenario:       Defining a concept (sharing, kindness, patience)
Narrator Line:  "[Concept] means [simple definition]."
                [2s pause]
                "When you [example], that's [concept]!"
Timing Notes:   2s pauses. Warm, affirming tone.
                Definition must be 3–8 words.
```

### Template E3 — Counting / Numbers
```
Scenario:       Counting objects or introducing numbers
Narrator Line:  "Let's count together!"
                [2s pause]
                "[Count slowly: One... two... three...]"
                [2s pause]
                "Great counting!"
Timing Notes:   Slow, deliberate counting. 1s between numbers.
                Celebratory tone on "Great counting!"
```

### Template E4 — Color / Shape Identification
```
Scenario:       Teaching colors or shapes
Narrator Line:  "Look! [Object] is [color/shape]."
                [2s pause]
                "Can you find something else that is [color/shape]?"
                [3s pause — time for child to look]
                "Great job!"
Timing Notes:   2s pauses. Interactive. 3s pause for child engagement.
```

### Template E5 — Moral / Lesson Summary
```
Scenario:       Wrapping up the episode's lesson
Narrator Line:  "So today we learned that [lesson]."
                [2s pause]
                "And that's why [moral]!"
                [2s pause]
                "Remember, [takeaway message]."
Timing Notes:   Warm, affirming tone. 2s pauses.
                Final line spoken with gentle emphasis.
```

## Closing Templates

### Template C1 — Standard Goodbye
```
Scenario:       Episode ending, standard close
Narrator Line:  "What a wonderful day in Little Learning Town!"
                [2s pause]
                "We learned so much today."
                [2s pause]
                "See you next time, friends!"
                [3s pause — hold on town wide shot, then fade]
Timing Notes:   Warm, gentle goodbye. 2s pauses. 3s hold at end.
```

### Template C2 — Lesson Recap
```
Scenario:       Episode ending with specific lesson recap
Narrator Line:  "And that's how [character] learned about [lesson]."
                [2s pause]
                "Remember, [key takeaway]."
                [2s pause]
                "We'll see you next time in Little Learning Town!"
Timing Notes:   Warm affirmating tone. 2s pauses. 4s hold.
```

### Template C3 — Song Ending
```
Scenario:       Episode ending with a song
Narrator Line:  "What a beautiful song!"
                [2s pause]
                "Singing makes everything better."
                [2s pause]
                "Goodbye for now, friends!"
Timing Notes:   2s after song ends. 2s between lines.
                Warm, appreciative tone.
```

### Template C4 — Bedtime Ending
```
Scenario:       Episode ending at bedtime/night
Narrator Line:  "The sun has set in Little Learning Town."
                [2s pause]
                "It's time for our friends to rest."
                [2s pause]
                "Sweet dreams, everyone. See you tomorrow!"
Timing Notes:   Softer, quieter tone. 3s pauses (sleepy pace).
                Voice gradually softens.
```

### Template C5 — Interactive Closing
```
Scenario:       Episode ending that engages the child
Narrator Line:  "We had so much fun today!"
                [2s pause]
                "Can you tell your grown-up what you learned?"
                [3s pause — space for child to respond]
                "I'll see you next time in Little Learning Town!"
Timing Notes:   Interactive. 3s pause for child response.
                Bright, encouraging tone.
```

## Template Usage Guidelines

| When to Use | Recommended Template |
|-------------|---------------------|
| First episode of the day | Opening T1 or T2 |
| Morning-themed episode | Opening T3 |
| Song-heavy episode | Opening T4 |
| Holiday / special episode | Opening T5 |
| Location change mid-episode | Transition T1 |
| Time jump | Transition T2 |
| New character introduction | Transition T3 |
| Activity change | Transition T4 |
| Problem/challenge arises | Transition T5 |
| Teaching a concept | Transition T6 + Educational E1–E5 |
| Day/night shift | Transition T7 |
| Group scene | Transition T8 |
| End of episode (general) | Closing C1 |
| End of episode (lesson recap) | Closing C2 |
| End of episode (song ending) | Closing C3 |
| Bedtime episode | Closing C4 |
| Interactive ending | Closing C5 |
