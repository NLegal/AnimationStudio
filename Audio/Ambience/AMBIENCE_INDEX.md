## Introduction

Ambient audio is the invisible foundation of every scene. While sound effects and Foley draw attention to specific actions, ambience creates the world that exists between those actions. A well-crafted ambient bed tells the audience where they are, what time of day it is, and how the world feels — all without demanding attention.

Children are especially sensitive to background atmosphere. The right ambience creates comfort and familiarity. The wrong ambience creates unease.

**Guiding Principles:**
- Subtlety over presence: ambience supports, never distracts
- Loopable: all ambiences must be seamless for indefinite playback
- Dynamic: provide layers that can be mixed to match scene intensity
- Warm and inviting: even "empty" spaces should feel safe

**Naming Convention:** `AMB_Location_###`

**Example:** `AMB_Indoor_001.wav`

**Format:** Stereo, 48 kHz, 24-bit, loopable .wav

## Mixing Guide

### Layering Rules
1. Always start with the base location ambience (Indoor/Outdoor)
2. Add Nature layer if scene is outdoors
3. Add Weather layer if conditions are notable
4. Never exceed 3 ambient layers simultaneously
5. Each layer should be at least 3dB below the previous layer in priority

### Crossfade and Looping
- All ambience files are seamless loopable
- Crossfade at loop point: 500ms to 1s
- Check for phase issues when layering two looped files
- Verify loop points at -60dB to ensure no click

### Volume Hierarchy (Reference)
| Element | RMS Level (relative) | Peak Level |
|---------|---------------------|------------|
| Dialogue | 0dB (reference) | -6dB |
| Music | -6dB to -9dB | -3dB |
| SFX (spot) | -6dB to -12dB | -3dB |
| Foley | -8dB to -15dB | -6dB |
| Ambience | -14dB to -18dB | -10dB |
| Weather layer | -16dB to -20dB | -12dB |

### EQ Guidelines for Ambience
- Roll off below 60Hz to avoid rumble buildup
- Gentle dip at 1-4kHz (dialogue clarity zone)
- High shelf boost above 10kHz for air (optional)
- Use mid/side processing: keep ambience wider, center clear for dialogue

## Production Notes

### Recording Sourcing
- Prefer original field recordings for authenticity
- Licensed library ambiences acceptable with documentation
- Synthesized ambience only for impossible locations
- Credit all sources in metadata

### Processing Chain
1. Noise reduction (gentle, preserve texture)
2. EQ shaping (per guidelines above)
3. Compression (2:1 ratio, gentle knee, for consistency)
4. Limiting (-3dB ceiling, catch peaks only)
5. Looping (zero-crossing edit, test for seamlessness)
6. Metadata embedding

### Quality Checklist
- [ ] Seamless loop (no click, no volume dip)
- [ ] No audible artifacts or noise floor pumping
- [ ] Appropriate for preschool audience (no scary elements)
- [ ] Works as standalone and as layer
- [ ] Volume meets spec relative to dialogue
- [ ] Metadata complete
- [ ] Archival copy saved as .wav 24-bit 48kHz
