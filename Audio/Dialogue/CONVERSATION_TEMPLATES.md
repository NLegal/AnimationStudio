## Template 1: Greetings

### Structure
```
[Character A]:  Greeting + [name/enthusiasm]
[Character B]:  Return greeting + [question/comment]
[Character A]:  Response + [energy match]
```

### Variation 1A — Standard Greeting (Lily + Ben)
```
LILY:
(hopping happily)
"Hi, Ben! Good morning!"

BEN:
(waving, calm smile)
"Good morning, Lily! Ready to play?"

LILY:
(excited)
"Yes! What should we do today?"
```

### Variation 1B — Morning Greeting (Sun + Chicken)
```
SUN:
(bright, warm)
"Good morning, Sunny!"

CHICKEN:
(perky, flapping)
"Good morning, Mr. Sun! Time to wake everyone up!"

SUN:
(beaming)
"Let's do it together!"
```

### Variation 1C — Shy Greeting (Cat + Mouse)
```

(quiet, half-hidden)
"H-hello, Mouse."

MOUSE:
(adjusting glasses, friendly)
"Hello, Kitty! Did you bring your new drawing?"

CAT:
(perking up slightly)
"Yes. Want to see?"
```

### Variation 1D — Enthusiastic Greeting (Dog + Horse)
```
DOG:
(bouncing, tail wagging)
"Dash! Dash! Guess what?!"

HORSE:
(eager, ready to run)
"What? What is it? A race?!"

DOG:

"Best day ever! Let's go!"
```

## Template 2: Problem-Solution Dialogue

### Structure
```
[Character A]:  Notice problem + emotional reaction
[Character B]:  Offer help + ask question
[Character A]:  Explain problem
[Character B]:  Propose solution
[Character A + B]:  Work together + resolution
[Character A]:  Express gratitude + positive closing
```

### Variation 2A — Broken Toy (Ben + Lily)
```
LILY:
(sad, ears drooping)
"Oh no... my music box is broken."

BEN:
(kind, approaching)
"I can help. Can I see it?"

LILY:
(hopeful, holding it out)
"Be careful. It's special."

BEN:
(examining, thoughtful)
"Hmm... the wheel is stuck. Let's fix it together."

[They work together — sound of fixing]

BEN:
(proud)
"There! Try it now."

LILY:
(turning handle, music plays — delighted)
"It works! Thank you, Ben! You're the best builder!"

BEN:
(smiling, warm)
"Building and fixing — that's what friends do!"
```

### Variation 2B — Lost Item (Police Officer Beaver + Daisy)
```
DAISY:
(panicked, looking around)
"Oh no! My bow! My pink bow is gone!"

POLICE OFFICER BEAVER:
(kneeling down, calm)
"Is everything okay, Daisy? Tell me what happened."

DAISY:
(teary)
"My favorite bow fell off somewhere."

POLICE OFFICER BEAVER:
(thoughtful, tipping hat)
"Let's retrace your steps. Where did you play today?"

DAISY:
(thinking)
"The playground... and the pond..."

POLICE OFFICER BEAVER:
(standing, confident)
"We'll check both places. Slow and steady finds the way!"

[At the pond, they find the bow]

DAISY:
(happy, putting on bow)
"You found it! Thank you, Officer Bucky!"

POLICE OFFICER BEAVER:
(warm smile)
"Community first! Now you look perfect again."
```

## Template 3: Educational Q&A

### Structure
```
[Teacher Character]:  Question + context
[Student Character]:  Attempt/guess
[Teacher Character]:  Affirm/redirect + correct answer
[Teacher Character]:  Elaborate in simple terms
[Student Character]:  Repeat or apply knowledge
[Teacher Character]:  Positive reinforcement
```

### Variation 3A — Teacher Owl + Lily (Science)
```
TEACHER OWL:
(holding up an apple)
"Lily, what do you think — will this apple float or sink?"

LILY:
(giggling, pointing down)
"I think it will sink! It's heavy!"

TEACHER OWL:
(warm, encouraging)
"Good guess! Let's try it."

[Places apple in water — it floats]

LILY:
(surprised, eyes wide)
"It floated! But it's heavy!"

TEACHER OWL:
(nodding wisely)
"Apples have air inside them. Air helps them float!"

LILY:
(touching the apple)
"Air? Inside an apple?"

TEACHER OWL:
(smiling)
"Exactly. Now... can you find something else that might float?"
```

### Variation 3B — Doctor Panda + Ben (Health)
```
DOCTOR PANDA:
(gentle, holding a carrot)
"Ben, what does this vegetable do for our bodies?"

BEN:
(thinking)
"Makes us strong?"

DOCTOR PANDA:
(delighted)
"Right! Carrots help our eyes see clearly."

BEN:
(looking at the carrot)
"I want strong eyes! Can I try one?"

DOCTOR PANDA:
(handing it over)
"Crunchy and healthy. How does it taste?"

BEN:
(munching)
"Sweet! And crunchy!"

DOCTOR PANDA:
(beaming)
"Healthy bodies are happy bodies!"
```

### Variation 3C — Farmer Goat + Cow (Nature)

## Template 4: Group Interaction

### Structure
```
[Leader Character]:  Propose group activity
[Group]:  Enthusiastic response
[Character A]:  Contribute idea/task
[Character B]:  Contribute different idea/task
[Character C]:  Offer help or materials
[Leader]:  Unite the group + action
[All]:  Work together + positive outcome
```

```
"Let's build a fort! Who wants to help?"

ALL:
(cheering)
"Yeah!"

(eager, bouncing)

FORT COMPLETE

(crawling inside)
"It's so cozy in here!"

(grinning)
"Best fort in Little Learning Town!"

DAISY:
(snuggling)
"This calls for a song!"

BEN:
(proud)
"We built it together. Teamwork!"
```

## Template 5: Conflict Resolution

### Structure
```
[Character A]:  Express frustration (name the feeling)
[Character B]:  Express different want (also valid)
[Third Character or Narrator]:  Notice conflict + intervene
[Intervener]:  State the problem neutrally
[Both]:  Explain their perspective
[Intervener]:  Suggest compromise or taking turns
[Both]:  Agree + resolve positively
[Intervener]:  Affirm the resolution
```

### Variation 5A — Sharing a Toy (Lily + Charlie, mediated by Teacher Owl)
```
LILY:
(holding a toy, upset)
"I was playing with this first!"

CHARLIE:
(reaching for it)
"But I want a turn now!"

TEACHER OWL:
(approaching calmly)
"I see two friends who both want the same toy."

LILY:
(still holding it)
"I'm not done yet."

CHARLIE:
(frustrated)
"But I've been waiting!"

TEACHER OWL:
(kneeling between them)
"How about this — Lily, you play for two more minutes. Then it's Charlie's turn. Charlie, you can watch and get ready."

LILY:
(thinking, then nodding)
"Okay. Two more minutes."

CHARLIE:
(relaxing)
"Okay. I can wait."

[Timer sound — 2 minutes]

LILY:
(handing it over)
"Your turn, Charlie. It's fun!"

CHARLIE:
(taking it, grateful)
"Thank you, Lily. Your turn next!"

TEACHER OWL:
(beaming)
"Sharing makes playtime better for everyone."
```

### Variation 5B — Different Ideas (Daisy + Ben, mediated by Lily)

```
"This is the best idea ever!"

BEN:

```

## Template 6: Song Introduction Dialogue

### Structure
```
[Character]:  Express feeling or observation
[Character]:  Connect feeling to a song idea
[Character]:  Invite others/audience to join
[All]:  Transition into song
```

```
(hopping excitedly)
"Let's sing the Yellow Song! Everybody ready?"

[Song begins: "The Yellow Song"]
```

## Template Usage Guidelines

| Episode Type | Suggested Templates |
|-------------|-------------------|
| Morning routine | Greeting A/B, Song C |
| Learning episode | Educational Q&A A/B/C, Problem-Solution B |
| Friendship episode | Conflict Resolution A/B/C, Group Interaction A |
| Music episode | Song Introduction A–E, Group Interaction C |
| Adventure episode | Problem-Solution C, Greeting C |
| Bedtime episode | Song Introduction D, Greeting D (modified) |
| Community episode | Group Interaction B, Problem-Solution B |
| Holiday episode | Greeting all variations, Group Interaction A |

### Template Flexibility
- Templates are starting points — adapt for character voice patterns
- Keep all resolutions positive
- Every character must sound like themselves
- Educational content should feel organic, not forced
- Leave space for call-and-response (2–3 second pauses)
