# Dialogue Standards

> **Version:** 1.0
> **Series:** Little Learning Town
> **Studio:** AI Nursery Rhyme Studio
> **Audience:** Preschool children ages 2–6

---

## Philosophy

Preschool dialogue should feel like a warm conversation with a trusted friend.

Every word choice, sentence structure, and vocal delivery must support:
- **Comprehension** — children must understand immediately
- **Engagement** — dialogue invites participation
- **Emotional safety** — never scary, mean, or confusing
- **Learning** — every interaction teaches something
- **Joy** — dialogue should make children smile

---

## Sentence Length

| Character Type | Ideal Length | Maximum | Example |
|----------------|-------------|---------|---------|
| Young children (2–4) | 3–5 words | 7 words | "I like red!" |
| Older children (5) | 4–8 words | 10 words | "Let's build a tower together!" |
| Adult characters | 5–12 words | 15 words | "Healthy bodies are happy bodies." |
| Narrator | 5–12 words | 15 words | "Today, our friends are learning about sharing." |
| Songs | 3–8 words per line | 10 words | "Twinkle, twinkle, little star!" |

### Why Short Sentences

- Preschool attention spans are 3–5 minutes per segment
- Working memory holds 2–3 pieces of information
- Short sentences reduce cognitive load
- Pauses between sentences allow processing
- Each sentence should deliver one idea

---

## Vocabulary

### Approved Word Types
- Common nouns (ball, tree, house, friend)
- Action verbs (run, jump, sing, share, help)
- Color words (red, blue, green, yellow)
- Number words (one, two, three)
- Feeling words (happy, sad, excited, scared)
- Size words (big, small, tall, tiny)
- Location words (up, down, in, out, under)
- Question words (what, where, who, how, why)

### Avoid
| Category | Examples | Reason |
|----------|----------|--------|
| Idioms | "Piece of cake", "Hit the road" | Literal-minded children get confused |
| Abstract concepts | "Justice", "Obligation" | Beyond developmental range |
| Complex time | "Next Thursday", "In a fortnight" | Use "today", "tomorrow", "later" |
| Sarcasm | "Oh, great..." | Children take words literally |
| Contradictions | "I love to hate..." | Confusing for binary thinkers |
| Passive voice | "The ball was thrown" | Use "Ben threw the ball" |
| Negatives in instructions | "Don't run" | Use "Please walk" instead |
| Tag questions | "That's fun, isn't it?" | Too complex for comprehension |

## Tone Guidelines

### Always Supportive
| Situation | Correct | Incorrect |
|-----------|---------|-----------|
| Mistake | "Let's try again!" | "You did it wrong." |
| Sad friend | "It's okay. I'm here." | "Don't be sad." |
| Slow learner | "Take your time." | "Hurry up!" |
| Excited child | "Wow! Tell me more!" | "Calm down." |
| Sharing | "That was very kind!" | "Good job." (vague) |

### Always Encouraging
- Praise effort, not outcome: "You worked so hard!"
- Acknowledge feelings: "I see you're frustrated."
- Offer help: "Let's do it together."
- Celebrate small wins: "You did it!"

### Never
| Forbidden | Example | Alternative |
|-----------|---------|-------------|
| Sarcasm | "Well, that was smart." | "Let's think about this." |
| Teasing | "You're so silly!" | "That was funny!" |
| Put-downs | "That's not how you do it." | "Let me show you a way." |
| Whining | "But I don't wannaaaa..." | "I don't want to. Can we try later?" |
| Threats | "If you don't share..." | "Sharing is fun! Let's try." |
| Name-calling | "You're a bad friend." | "That hurt my feelings." |

## Call-and-Response Patterns

Educational songs and dialogue should include call-and-response:

### How It Works
1. **Call** — Character says/asks something
2. **Pause** — 2–3 seconds for child to respond
3. **Response** — Child (at home) answers
4. **Affirmation** — Character reinforces: "That's right!"

### Examples
```
Lily:     [Call]    "What color is this apple?"
          [Pause]   [3s — child answers at home]
Lily:     [Affirm]  "Yes! Red! Great job!"

Ben:      [Call]    "Let's count the blocks. One..."
          [Pause]   [1s between numbers]
Ben:      [Count]   "Two... three..."
          [Pause]   [1s]
Ben:      [Affirm]  "Three blocks! We did it!"
```

### Call-and-Response Types
| Type | Example | Pause |
|------|---------|-------|
| Fill-in-the-blank | "Twinkle, twinkle, little ___" | 2s |
| Question-answer | "What does a cow say?" | 3s |
| Echo | "Say 'hello'!" | 2s |
| Action response | "Can you clap your hands?" | 3s |
| Choice | "Is this big or small?" | 3s |

## Repetition Guidelines

Repetition is the backbone of preschool learning.

### How Many Times
| Element | Repetitions Per Scene | Notes |
|---------|----------------------|-------|
| Key vocabulary word | 3–5 times | Before, during, and after activity |
| Song chorus | 3–5 times | Each repetition reinforces |
| Concept | 4–6 times | Across the episode |
| Question pattern | 2–3 times | Same structure, different examples |
| Catchphrase | 1–2 times per appearance | Character signature |

### How to Repeat Naturally
1. **Introduce**: "This is a triangle."
2. **Use in context**: "Look at the triangle roof."
3. **Question**: "What shape is this?"
4. **Reinforce**: "That's right! A triangle!"
5. **Celebrate**: "Triangles are amazing!"

## Question Types

| Type | Description | Example | Pause |
|------|-------------|---------|-------|
| Open-ended | Encourages thinking | "What do you think will happen?" | 3–4s |
| Closed (Yes/No) | Simple confirmation | "Is this a circle?" | 2–3s |
| Rhetorical | Dramatic, no answer needed | "Isn't that wonderful?" | 2s |
| Choice | Pick from options | "Do you want apples or oranges?" | 3s |
| Fill-in-blank | Complete the sentence | "A cow says ___" | 2s |
| Recall | Remember and respond | "What did Lily do first?" | 3–4s |

### Question Distribution
- 40% Closed (yes/no) — confidence building
- 30% Fill-in-blank — pattern recognition
- 20% Choice — decision making
- 10% Open-ended — critical thinking
- 0% Rhetorical (to children) — always give processing time

## Emotional Dialogue

### How Characters Express Feelings

| Emotion | Appropriate Phrasing | Avoid |
|---------|---------------------|-------|
| Happy | "I'm so happy!" | "I feel euphoric." |
| Sad | "I feel sad." | "I'm depressed." |
| Scared | "I'm scared of thunder." | "I'm terrified." |
| Excited | "I can't wait!" | "I'm ecstatic." |
| Frustrated | "This is hard." | "I hate this." |
| Proud | "I did it!" | "I'm superior." |
| Grateful | "Thank you!" | "I'm indebted." |
| Surprised | "Wow!" | "I'm astonished." |

### Emotional Dialogue Structure
1. **Name the feeling**: "I feel [emotion]."
2. **Explain why**: "Because [reason]."
3. **Seek or offer help**: "Can you help me?" / "I can help."
4. **Resolve positively**: "Now I feel better!"

### Example Sequence
```
Daisy:  "I feel sad."                [Name]
Ben:    "Why, Daisy?"
Daisy:  "My music box is broken."    [Explain]
Ben:    "Let's fix it together."     [Offer help]
Daisy:  "Thank you, Ben!"
Ben:    [fixes it]
Daisy:  "It works! Now I feel happy!" [Resolve]
```

## Dialogue Timing

### Turn-Taking
| Element | Duration | Notes |
|---------|----------|-------|
| Between lines (same character) | 1–2 seconds | Natural pause |
| Between characters (turn-taking) | 1–2 seconds | Wait for processing |
| Overlap (excitement) | 0.5s | Characters talk over each other happily |
| After a question | 2–3 seconds | Space for answer |
| Before a response | 1–2 seconds | Character processing |
| Laugh before speaking | 0.5–1s | Let laugh land |
| Emotional pause | 2–3 seconds | Let moment breathe |

### Overlap Rules
- **Allowed**: Excited interruptions, finishing each other's sentences, group cheers
- **Not allowed**: Talking over someone sad, interrupting a song, cutting off educational explanation

## Dialogue Formatting in Scripts

Every dialogue line should follow this format:

```
[CHARACTER NAME]
[Emotion/action in brackets — optional]
"Dialogue line."
[Timing note — optional]
```

### Example
```
LILY
(excited, hopping)
"Look what I found!"
[2s pause — shows object]

BEN
(curious, leaning in)
"What is it?"
[1s pause]

LILY
(proud)
"A butterfly! Isn't it beautiful?"
```

## Quality Checklist

Every dialogue scene must verify:

- [ ] Shortest possible sentences for the message
- [ ] Vocabulary appropriate for ages 2–6
- [ ] No idioms, sarcasm, or abstract concepts
- [ ] Tone is supportive, encouraging, and kind
- [ ] Each character's speech pattern is consistent
- [ ] Emotional moments follow name-explain-resolve structure
- [ ] Questions include adequate pause time
- [ ] Key vocabulary repeated 3–5 times
- [ ] Call-and-response includes pause and affirmation
- [ ] No dialogue overlap during emotional or educational moments
- [ ] All character voices are distinct and recognizable
- [ ] Dialogue always resolves positively
