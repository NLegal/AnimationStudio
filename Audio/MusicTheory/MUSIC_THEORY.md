# Music Theory Reference for AI Prompt Engineers

## Overview

This guide covers the essential music theory concepts you need to write effective prompts for AI music generation tools (Suno, ACE-Step Studio). You do not need to be a musician — just understand these basics to produce consistent, high-quality children's music.

---

## Key Signatures

### Major Keys (Bright, Happy)

| Key | Accidentals | Notes | Character | Use For |
|-----|-------------|-------|-----------|---------|
| **C major** | None (0 ♯ / 0 ♭) | C D E F G A B C | Brightest, simplest | Alphabet, colors, numbers, dance |
| **G major** | 1 sharp (F♯) | G A B C D E F♯ G | Warm, bright | Animals, family, nature, lullabies |
| **D major** | 2 sharps (F♯, C♯) | D E F♯ G A B C♯ D | Bright, energetic | Transportation, exercise, dance |
| **F major** | 1 flat (B♭) | F G A B♭ C D E F | Gentle warmth | Bedtime, emotions, food, weather |

### Minor Keys (Use Rarely in Preschool)

Minor keys sound sad or serious. Avoid for standard content. Only use if a specific emotion song calls for it (e.g., "When I'm Sad").

| Key | Accidentals | Notes |
|-----|-------------|-------|
| **A minor** | None (relative of C) | A B C D E F G A |
| **E minor** | 1 sharp (F♯) | E F♯ G A B C D E |

## Common Chord Progressions for Children's Music

All progressions below use **diatonic chords** (only notes from the key signature — no borrowed or altered chords).

### I–IV–V–I (The Classic)

```
Key of C:  C → F → G → C
Key of G:  G → C → D → G
Key of F:  F → B♭ → C → F
```

**Feel**: Resolved, complete, traditional.
**Use**: Alphabet songs, nursery rhymes, endings.

### I–V–vi–IV (The Pop Progression)

```
Key of C:  C → G → Am → F
Key of G:  G → D → Em → C
Key of F:  F → C → Dm → B♭
```

**Feel**: Slightly emotional, uplifting.
**Use**: Verses, choruses with gentle emotion, morning routines.

### I–vi–IV–V (Doo-Wop)

```
Key of C:  C → Am → F → G
Key of G:  G → Em → C → D
```

**Feel**: Catchy, classic, bouncy.
**Use**: Dance songs, birthday songs, holiday songs.

### I–IV–I–V (Minimalist)

```
Key of C:  C → F → C → G
```

**Feel**: Simple, repetitive.
**Use**: Counting songs, interactive learning, call-and-response.

### vi–IV–I–V (Modern Pop)

```
Key of C:  Am → F → C → G
```

**Feel**: Contemporary, energetic.
**Use**: Upbeat dance songs, action songs.

## Rhythm Patterns

### 4/4 Time (Standard for Preschool Music)

Four beats per bar. The most common time signature in children's music.

```
Beat:  1   2   3   4    |   1   2   3   4
Count: ONE two three four | ONE two three four
```

### Common Rhythm Patterns

| Pattern | Description | Example |
|---------|-------------|---------|
| **Steady quarter notes** | 1-2-3-4 (walking pace) | "Twinkle Twinkle" verse |
| **Eighth-note feel** | 1-and-2-and-3-and-4-and (bouncy) | "Old MacDonald" chorus |
| **Syncopated** | Accent on off-beats (sophisticated) | Use sparingly in preschool |
| **3/4 Waltz** | 1-2-3, 1-2-3 (swaying) | Lullabies, bedtime songs |

### Tips for Rhythm in Prompts

- Use "steady drum beat on 2 and 4" to get a standard backbeat
- Use "eighth-note rhythm" for energetic, driving songs
- Use "waltz feel" or "3/4 time" for gentle, swaying songs
- Use "strong downbeat on 1" to help children feel the pulse
- Use "hand claps on every other beat" for participatory feel

## Melody Writing Tips

### Preschool Melody Principles

| Principle | Why | How in Prompts |
|-----------|-----|----------------|
| **Stepwise motion** | Easier to sing and remember | "Simple stepwise melody" |
| **Narrow range** | Children's vocal range is limited (C4–C5) | "Limited vocal range, comfortable for children" |
| **Repeating phrases** | Builds familiarity and learning | "Repetitive melodic phrases" |
| **Call-and-response** | Engages the listener | "Call and response structure" |
| **End on tonic** | Gives a sense of completion | "Melody resolves to the root note" |
| **Question-answer pairs** | Two phrases that feel like conversation | "Question and answer melody" |

### Interval Guide

| Interval | Semitones | Sound | Use |
|----------|-----------|-------|-----|
| Unison (same note) | 0 | Repetition | Call-and-response |
| Major 2nd (up 2 frets) | 2 | Walking up | Stepwise movement |
| Major 3rd (up 4 frets) | 4 | Happy leap | "Do-Re-Mi" feel |
| Perfect 4th (up 5 frets) | 5 | Strong lift | "Here Comes the Sun" |
| Perfect 5th (up 7 frets) | 7 | Open, strong | "Twinkle Twinkle" leap |
| Octave (up 12 frets) | 12 | Complete | Too wide for preschoolers |

## Vocabulary for AI Music Prompts

### Tempo Descriptors

| Term | BPM Range | Use in Prompts |
|------|-----------|----------------|
| Very slow / Largo | 40–60 | "Very slow, lullaby tempo" |
| Slow / Adagio | 60–80 | "Slow and gentle, bedtime feel" |
| Moderate / Andante | 80–100 | "Moderate walking pace" |
| Moderately fast / Allegro | 100–120 | "Upbeat and cheerful" |
| Fast / Vivace | 120–140 | "Fast and energetic, dance song" |
| Very fast / Presto | 140+ | Avoid in preschool |

### Key / Mood Descriptors

| Term | Meaning |
|------|---------|
| Major key | Bright, happy, positive |
| Minor key | Sad, serious, gentle (use sparingly) |
| Diatonic | Only using notes from the key (no chromatic notes) |
| Tonic | The home note / root of the key |
| Bright | High-frequency emphasis, cheerful timbre |
| Warm | Reduced high frequencies, soft, cozy |

### Instrumentation Descriptors

| Term | Sound |
|------|-------|
| Acoustic piano | Warm, natural, classic |
| Xylophone | Bright, playful, educational |
| Acoustic guitar (strummed) | Folk, friendly, rhythmic |
| Hand drums | Organic, bouncy, fun |
| Bells / Glockenspiel | Magical, bright, tinkly |
| Tambourine | Cheerful, jangly, energetic |
| Recorder | Simple, school-like, sweet |
| Ukulele | Light, happy, tropical |
| Marimba | Warm, wooden, rich |
| Wood block / Claves | Click, rhythmic, counting |

### Mood Descriptors

| Term | Meaning |
|------|---------|
| Cheerful | Happy, bright, uplifting |
| Playful | Fun, bouncy, mischievous |
| Gentle | Soft, calm, tender |
| Energetic | Fast, excited, high-energy |
| Calm | Relaxed, peaceful, soothing |
| Educational | Clear, repetitive, intentional |
| Celebratory | Festive, exciting, triumphant |
| Sweet | Warm, affectionate, loving |

### Dynamics Descriptors

| Term | Meaning |
|------|---------|
| Piano (p) | Soft, quiet |
| Mezzo-piano (mp) | Moderately soft |
| Mezzo-forte (mf) | Moderately loud (default for children's music) |
| Forte (f) | Loud, strong (choruses) |
| Crescendo | Gradually getting louder |
| Decrescendo | Gradually getting softer |
| Stable dynamics | Even volume throughout (good for learning) |

### Structure Descriptors

| Term | Meaning |
|------|---------|
| Intro | Opening section, establishes key and tempo |
| Verse | Tells the story, new lyrics each time |
| Pre-chorus | Builds tension before the chorus (optional) |
| Chorus | Main hook, repeats with same lyrics |
| Bridge | New section, different feel, usually once |
| Outro | Ending section, winds down |
| Tag ending | Repeat last phrase 2-3 times with fade |

## Full Prompt Template

Combine terms from above into a structured prompt:

```
A [mood] [genre] [structure] about [topic],
[instrumentation],
[tempo] tempo,
[key] key,
[vocal style],
[production quality],
approximately [duration].
```

### Example

```
A cheerful educational preschool song about sharing toys,
female lead vocal with children's choir,
acoustic guitar and xylophone,
upbeat 110 BPM tempo,
C major key,
bright piano and hand drums,
simple repetitive melody,
clear vocals,
approximately two minutes.
```

```

Keys:     C major (brightest) | G major (warm) | F major (gentle)
Feel:     4/4 time, strong downbeat, steady rhythm
Melody:   Stepwise, narrow range, repeating, call-and-response
Chords:   I-IV-V-I (classic) | I-V-vi-IV (pop) | I-vi-IV-V (doo-wop)
Instruments: Piano, xylophone, acoustic guitar, hand drums, bells
Avoid:    Heavy bass, distortion, complex arrangements, minor keys
Duration: 30s / 1min / 2min / 3min / 5min
Vocal:    Clear, bright, medium-high pitch, cheerful delivery
Mix:      Vocals clear above instruments, -14 LUFS, no harsh frequencies
```
