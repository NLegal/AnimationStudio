# Educational Asset Library — Little Learning Town

## Design Philosophy

Educational assets in Little Learning Town bridge the gap between **learning and play**. Every item is designed to be visually engaging, tactilely inviting, and pedagogically purposeful. The design language mirrors the toy library — bright, rounded, child-safe — with additional emphasis on **clarity of information**, **legibility**, and **interactive learning cues**.

## Design Principles

- **Readable Typography** — Large, bold, sans-serif fonts with high contrast against backgrounds.
- **Clear Color Coding** — Subjects use distinct color families: red for math, blue for science, yellow for alphabet, green for art, purple for classroom.
- **Tactile Engagement** — Textures, raised surfaces, and grooves invite touch and manipulation.
- **Visual Simplicity** — Information is presented in digestible chunks without visual clutter.
- **Kid-Sized Scale** — Items are proportioned for preschool and early elementary use.
- **Durable Construction** — Reinforced edges, laminated surfaces, spill-resistant materials.

## Quality Standards

Educational assets follow the same global art style quality standards as all Little Learning Town assets, with additional requirements:

| Standard | Requirement |
|---|---|
| Legibility | Text must be readable at 1.5× the typical viewing distance |
| Safety | All corners rounded to 3 mm minimum radius |
| Durability | Laminated or coated for wipe-clean maintenance |
| Color Consistency | Subject color coding maintained across entire category |
| Scale Accuracy | Sized for child use (not adult) |
| Interactive Potential | Learning through manipulation, not passive observation |
