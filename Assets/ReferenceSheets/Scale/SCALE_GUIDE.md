# Scale Reference Guide

## Introduction

Scale consistency is critical to building believable scenes. In the Animation Studio world, characters stand approximately 30-50 cm tall. All assets must be sized relative to these characters. This guide defines the six scale categories and provides real-world reference analogs.

Keeping scale consistent ensures:
- Characters interact naturally with objects
- Scenes look proportional and believable
- Assets can be reused across episodes without visual mismatch
- Production renders faster with pre-validated scales

---

## Scale Reference Chart

### Tiny — Under 5 cm
Objects smaller than a child's palm.

| Reference Object | Real-World Analog | Example Assets |
|---|---|---|
| Marble | Standard glass marble | Marbles, beads, small buttons |
| Button | Shirt button | Buttons, coins |
| Coin | US quarter / euro | Play money, tokens |
| Grape | Single grape | Small berries, peas |
| Eraser | Pencil eraser | Crayon nubs, chalk bits |

**World note**: Tiny objects are often multiple in a scene (a bowl of blueberries, a pile of buttons). They should never be used as single focal assets.

---

### Small — 5 to 20 cm
Handheld objects that fit in one or two hands.

| Reference Object | Real-World Analog | Example Assets |
|---|---|---|
| Apple | Standard apple | All fruit (apple, orange, pear) |
| Toy Car | Hot Wheels / Matchbox | Toy cars, small vehicles |
| Cup | Tea cup / juice glass | Cups, mugs, small bowls |
| Book | Small picture book | Storybooks, notebooks |
| Pencil | Standard #2 pencil | Writing tools, crayons |
| Ball | Tennis ball | Balls, small toys |
| Banana | Standard banana | Bananas, carrots, cucumbers |
| Sandwich | Half sandwich | Sandwiches, cookies, donuts |

**World note**: Most food items and handheld toys fall into this category. Characters can easily pick these up with one hand.

---

### Medium — 20 to 100 cm
Furniture and objects that require two hands or are stationary play items.

| Reference Object | Real-World Analog | Example Assets |
|---|---|---|
| Chair | Child's chair | All chairs, step stools |
| Backpack | Child's backpack | Backpacks, lunch boxes |
| Lamp | Desk lamp | Table lamps, nightlights |
| Pillow | Throw pillow | Pillows, stuffed animals |
| Globe | Desktop globe | Globes, science models |
| Toy Train | Wooden train set | Toy trains, large trucks |
| Plant Pot | Medium houseplant | Potted plants, floor vases |
| Clock | Wall clock | Clocks, wall decor |

**World note**: This is the most common scale category. Characters sit on medium chairs, carry medium backpacks, and play with medium toys. These objects define the everyday environment.

---

### Large — 1 to 3 meters
Furniture and structures larger than a character but smaller than a room.

| Reference Object | Real-World Analog | Example Assets |
|---|---|---|
| Table | Child's play table | Tables, desks, counters |
| Sofa | Two-seater couch | Sofas, benches |
| Door | Standard doorway | Doors, cabinets |
| Refrigerator | Mini fridge | Kitchen appliances |
| Bookshelf | Low bookshelf | Bookshelves, shelving units |
| Bed | Child's bed | Beds, cribs, cots |
| Bathtub | Standard tub | Bathtubs, laundry baskets |
| Mirror | Full-length mirror | Mirrors, wardrobes |

**World note**: Large objects define rooms. Characters walk around them, climb on them, or use them as backdrops. They should never block the character's face or create awkward sightlines.

---

### Huge — 3 to 10 meters
Outdoor objects and structures that dominate a scene.

| Reference Object | Real-World Analog | Example Assets |
|---|---|---|
| Tree | Small deciduous tree | Trees, large bushes |
| Vehicle | Compact car | Playground vehicles, carts |
| Slide | Playground slide | Slides, climbing structures |
| Billboard | Small sign | Classroom wall decor |
| Windmill | Garden windmill | Decorative outdoor structures |

**World note**: Huge objects sit in the background or define play spaces. Characters can stand next to them but cannot reach the top. They should be placed with care to avoid dwarfing the scene.

---

### Massive — 10+ meters
Background objects that define the world itself.

| Reference Object | Real-World Analog | Example Assets |
|---|---|---|
| Building | Two-story house | School buildings, houses |
| Water Tower | Small town tower | Towers, large structures |
| Big Tree | Large oak | Massive shade trees |
| Wind Turbine | Small turbine | Large outdoor structures |

**World note**: Massive objects are always background elements. They establish setting and environment. Characters never directly interact with them — they simply exist in the world.

---

## Character Scale Comparison

Characters in the Animation Studio world are **30-50 cm tall** (comparable to a toddler or young child).

| Object | Scale | vs Character |
|---|---|---|
| Apple | Small | Half the size of a character's head |
| Toy Car | Small | Fits in character's hand |
| Chair | Medium | Character sits comfortably |
| Table | Large | Reaches character's chest |
| Door | Large | Character reaches the doorknob |
| Tree | Huge | Character is tiny beneath it |

---

## Visual Reference Description

When placing assets in scenes, use these mental models:

- A character sitting at a table: The tabletop reaches their chest. Their feet dangle above the floor.
- A character holding an apple: The apple fills both hands. They bite into it comfortably.
- A character next to a tree: The tree trunk is wider than the character. The lowest branches are above their head.
- A character in a chair: Their knees bend at 90 degrees. Their back rests against the chair back. Their feet touch the floor.

---

## Scale Validation Checklist

- [ ] Asset size matches its category definition
- [ ] Relative to characters, the asset looks proportional
- [ ] Multiple assets in the same scene maintain consistent scale relationships
- [ ] Animated interactions (picking up, sitting on, reaching for) are physically possible at this scale
- [ ] Scale is recorded in the asset's metadata
