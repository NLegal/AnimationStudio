# Bathroom Asset Library — Little Learning Town

## Art Style & Philosophy

Bathroom assets follow the same **bright, clean, child-friendly** design language. Fixtures are rounded and colorful; tools are chunky and easy to grip; bath toys are extra playful. The bathroom should feel like a **safe, fun, welcoming space** — no harsh metals, no scary drains, no clinical whites. Pastel blues, greens, and yellows dominate.

Designed for bathroom routines, bath time play, doctor-play context, and daily hygiene education scenes.

---

## Naming Convention

```
BATH_Type_Number
```

Examples: `BATH_Fixture_004`, `BATH_Tool_009`, `BATH_Toy_003`
