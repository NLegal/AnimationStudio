# Holiday Prompt Templates

## Master Holiday Prompt Structure

```
[exact holiday item],
bright festive colors,
rounded edges,
child-safe,
Pixar-quality,
Cocomelon-inspired,
clean geometry,
celebratory feel,
highly detailed,
soft lighting,
consistent asset style,
8K,
masterpiece
```
