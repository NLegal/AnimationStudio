# Furniture Prompt Templates

## Master Furniture Prompt Structure

```

bright inviting colors,
rounded edges,
child-safe,
Pixar-quality,
Cocomelon-inspired,
clean geometry,
solid construction,
highly detailed,
soft lighting,
consistent asset style,
8K,
masterpiece
```
