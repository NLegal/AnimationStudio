# Toy Asset Library — Little Learning Town

## Design Philosophy

All toys in the Little Learning Town universe follow a distinct design language inspired by Pixar-quality, Cocomelon-style aesthetics. Every toy is designed to feel **touchable, safe, and delightful** — the kind of object a child would reach for immediately.

## Design Principles

- **Rounded Edges** — No sharp corners. Every block, car, and toy feature soft, beveled edges for visual safety.
- **Bright Primary Colors** — Red, blue, yellow, green dominate. Pastels used for softer toys. High saturation maintains visual pop.
- **Child-Safe Proportions** — Oversized to prevent choking hazard perception. Chunky, graspable forms.
- **Pixar-Quality Finish** — Smooth surfaces, subtle glossy reflections, satisfying solidity.
- **Expressive Simplicity** — Faces are friendly, features are clear, forms are readable at a distance.
- **Durability Signals** — Visual cues of thickness, sturdiness, and ability to withstand play.

## Quality Standards

Every toy asset must satisfy:

| Standard | Requirement |
|---|---|
| Global Art Style | Matches the bright, rounded, child-friendly universe |
| Child-Friendly | No sharp edges, no small parts visual, no distressing themes |
| Rounded Edges | 3–5 mm bevel on all hard surfaces |
| Correct Proportions | Chunky, slightly oversized relative to real-world scale |
| Standard Materials | Uses approved material palette (plastic, wood, fabric, foam) |
| Consistent Colors | Uses approved color palette per toy type |
| Scale Accuracy | Falls within specified scale range for its category |
| Metadata Complete | Asset ID, category, colors, materials, scale, animation metadata filled |
| Ready for Animation | Joints/ articulation points identified for rigging |
| Reusable | Designed to appear across multiple episodes and scenes |

## Animation Capability Key

| Term | Meaning |
|---|---|
| Static | Fixed pose, no moving parts |
| Simple | 1–2 moving parts (wheels roll, lid opens) |
| Articulated | Multiple joints (arms, legs, head) |
| Deformable | Soft body, squash/stretch capable |
| Interactive | Can be picked up, held, or manipulated by characters |
