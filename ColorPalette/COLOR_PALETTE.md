# Studio Color Palette

> **Version:** 1.0
> **Style:** Cocomelon-inspired, Pixar-quality
> **Principle:** Restrict palette — too many colors create visual chaos

## Color Rules

1. Always use pastel variants for large surfaces
2. Reserve saturated colors for small accents
3. Never use neon or fluorescent colors
4. Never use dark/moody colors for main elements
5. Backgrounds should use desaturated versions of palette
6. Characters should each own 1-2 signature colors from the palette
7. Holiday variants follow palette but add seasonal accents
