# Prop Library Index — Little Learning Town

## Introduction

The Prop Library is the reusable object catalog of Little Learning Town. Every prop is an independent, modular asset that can be placed into any scene, interior, or exterior set across episodes. Rather than generating objects from scratch each time, artists and AI workflows pull from this library to compose rich, consistent environments quickly.

Props follow the same design philosophy as the world itself: **safe, bright, warm, colorful, and child-friendly**. All props feature rounded edges, saturated but soft color palettes, and simple shapes that are instantly recognizable to preschool-aged children.

## Organization

Props are organized by functional category. Each category groups objects that naturally appear together in scenes — for example, all furniture props live under the Furniture category, all playground equipment under Playground, and so on.

## Naming Convention

Every prop receives a permanent identifier:

```
PROP_Category_Number
```

Examples:
- `PROP_Furniture_001` — Round Table
- `PROP_School_005` — Globe
- `PROP_Playground_003` — Seesaw

Numbers are three-digit zero-padded. **Once assigned, identifiers are never renamed or reused.** Retired props are marked deprecated but their ID is never recycled.

## Quality Standards

All props must pass these checks before joining the library:

- Matches the global art style (Cocomelon-inspired, Pixar-quality rounded shapes)
- Rounded edges — no sharp corners or pointed ends
- Bright, warm, non-neon colors from the approved palette
- Child-safe shapes — no small detachable-looking parts, no realistic dangerous objects
- Easily recognizable from silhouette alone
- Consistent scale relative to character heights (props should be roughly 30–120% of a child character's size)
- Clean topology — suitable for both still renders and animation
- No text, logos, watermarks, or branding on the prop surface
