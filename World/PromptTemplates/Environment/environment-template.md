# Environment Prompt Templates

## Master Template Structure

Every environment prompt follows this structure:

```
[Location description],
bright colorful [zone type],
rounded architecture,
soft pastel colors,
[distinctive features],
[weather/season],
Pixar-quality,
Cocomelon-inspired,
highly detailed,
cinematic lighting,
consistent world design,
child-safe,
vibrant,
masterpiece,
8k
```

---

## Base Components

| Component | Description | Example |
|-----------|-------------|---------|
| Location description | Named place in Little Learning Town | "Sunny Meadows residential street" |
| Zone type | Category of environment | "preschool town neighborhood" |
| Art style | Visual language identifier | "rounded architecture, soft pastel colors" |
| Quality tags | Production quality markers | "Pixar-quality, Cocomelon-inspired" |
| Lighting | Time of day and lighting mood | "cinematic lighting, golden hour" |
| Weather | Atmospheric condition | "sunny with fluffy white clouds" |
| Season | Seasonal context | "spring with blooming flowers" |

## Visual Reference Checklist

Each prompt should clearly communicate:
- World name (Little Learning Town or zone-specific name)
- Zone category (residential, downtown, school, nature, fantasy)
- Distinctive architectural features
- Color palette direction
- Lighting and atmosphere
- Child-safe quality assurance
- Production quality standard

## Style Keywords Reference

Always include a mix of:
- **Quality**: Pixar-quality, Cocomelon-inspired, highly detailed, masterpiece, 8k
- **Style**: rounded architecture, soft pastel colors, bright colorful
- **Safety**: child-safe, friendly atmosphere, clean
- **Lighting**: cinematic lighting, golden hour, soft shadows
- **Consistency**: consistent world design, cohesive color palette
