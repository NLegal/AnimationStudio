# Studio Lighting Guide

## Design Philosophy

Studio lighting setups are used for **promotional shots, character introduction cards, product shots, and key art**. These are pre-composed lighting recipes that make subjects look their best. Keep lighting flattering, warm, and dimensional.

---

## Three-Point Lighting Setup

### Description
The classic studio lighting standard. Three lights work together to create a polished, professional look with depth and dimension. Perfect for character portraits and introduction shots.

### Diagram

```
                         [Back/Rim Light]
                              │
                              │  (behind subject, angled down)
                              │
    [Key Light] ──────────── ● ──────────── [Fill Light]
    (45° left,      Subject               (45° right,
     brighter,                             softer,
     main light)                           fills shadows)
```

| Light | Position | Intensity | Color Temp | Purpose |
|-------|----------|-----------|------------|---------|
| **Key Light** | 45° to the left of camera, slightly above eye level | 100% (primary) | 4500K (warm white) | Main light source, defines shape and mood |
| **Fill Light** | 45° to the right of camera, at eye level | 40–50% (softer) | 5000K (slightly cooler) | Softens shadows, reveals detail |
| **Back/Rim Light** | Behind subject, 30° above, pointing down | 70–80% | 4200K (warm) | Separates subject from background, adds depth |

### Prompt Template

```
three-point studio lighting, character portrait lighting,
warm key light from left, soft fill light from right,
rim light highlighting edges, professional studio setup,
polished character presentation, dimensional lighting,
soft shadows, warm flattering tones, clean background,
character-focused lighting, cinematic portrait
```

### Best Used For
- Character introduction cards
- Character reference sheets
- Group photos
- Key art / promotional images
- Thumbnail portraits

## Softbox Lighting

### Description
Diffused, even lighting that wraps around the subject. Creates soft, barely-visible shadows and a smooth, clean look. The most flattering light for products, toys, and close-up shots.

### Diagram

```
    ┌──────────────┐
    │   Softbox    │ ← Large diffused light source
    │  (large)     │
    └──────┬───────┘
           │
           │  (close to subject, slightly above)
           │
           ●
        Subject


    ┌─────────────────────────────────┐
    │   White Bounce / Reflector      │ ← Opposite side, fills
    │   (opposite softbox)            │    shadows naturally
    └─────────────────────────────────┘
```

| Light | Position | Intensity | Color Temp | Purpose |
|-------|----------|-----------|------------|---------|
| **Main Softbox** | 30° from camera, close to subject, above eye level | 80% | 4800K (neutral-warm) | Primary soft illumination |
| **Bounce Reflector** | Opposite side of softbox | Passive (no power) | N/A | Bounces light into shadows |

### Prompt Template

```
softbox lighting, large diffused light source,
smooth even illumination, soft gentle shadows,
flattering product lighting, clean professional look,
wrapped soft light, minimal shadow transition,
bright clear presentation, polished studio quality
```

### Best Used For
- Product shots (toys, food, props)
- Promotional merchandise images
- Clean character close-ups
- Thumbnail images
- Educational material illustrations

## Rim / Edge Lighting

### Description
A dramatic light from behind that creates a bright outline around the subject's edges. Separates the character from the background. Often combined with a darker or moodier main scene to make characters pop.

### Diagram

```
                   ┌───┐
                   │Light│ ← Rim light (behind subject)
                   └───┘
                      │
                      │  (aimed at subject's edges)
                      │
    [Camera] ──────── ●
                  Subject

    Result: Bright glowing edge on top/sides of character
```

| Light | Position | Intensity | Color Temp | Purpose |
|-------|----------|-----------|------------|---------|
| **Rim Light** | Behind subject, 45° above, aimed at back of head/shoulders | 90% | 4000K (slightly warm) | Creates edge glow for separation |
| **Ambient** | Soft front fill (optional) | 20–30% | 5000K | Prevents face from being too dark |

### Prompt Template

```
rim lighting, edge glow on character, backlight separation,
bright glowing outline, dramatic edge light, character pops
from background, warm rim highlights, cinematic separation,
depth through lighting, silhouette definition, professional
backlighting, dimensional edge glow
```

### Best Used For
- Dramatic character reveals
- Separating characters from busy backgrounds
- Emotional or important moments
- Night scenes with character focus
- Intro sequences with dramatic flair
