# Camera Angles Guide

## Design Philosophy

Camera angles are the **visual vocabulary** of storytelling. Consistent use of specific shots creates a recognizable language that young viewers learn to read intuitively. Always frame shots to feel **safe, warm, and inviting**.

---

## Wide / Establishing Shot

| Field | Description |
|-------|-------------|
| **Description** | Shows the full scene from a distance. The character occupies a small portion of the frame. The environment is the star. Used to orient the viewer to a new location. |
| **Distance** | Far — character is small in frame (approx 10–20% of frame height) |
| **When to Use** | Introducing a new location, showing where a scene takes place, transitions between locations, opening shots |
| **Prompt Template** | `wide establishing shot, full scene view, character small in frame, environment focus, beautiful location, clear overview, cinematic wide angle, shows entire setting, grand view, location introduction` |

```

    │  ☁️          🏔️               │
    │                              │
    │  🌳     ●      🏠            │  ← Character is small
    │                              │
    │        ─────                 │
    └──────────────────────────────┘
```

## Ultra Wide

| Field | Description |
|-------|-------------|
| **Description** | Even wider than a standard establishing shot. An epic, sweeping view of a landscape or large scene. Character is very small or not visible. Emphasizes scale and beauty. |
| **Distance** | Very far — landscape dominates, character tiny or absent |
| **When to Use** | Epic landscapes, showing the whole town, mountain views, beach panoramas, dramatic natural beauty |
| **Prompt Template** | `ultra wide shot, epic landscape view, sweeping panorama, vast beautiful scene, grand scale, majestic location, wide angle landscape, cinematic epic view, breathtaking scenery, panoramic establishing` |


## Medium

| Field | Description |
|-------|-------------|
| **Description** | Shows the character from the waist or knees up. The standard shot for dialogue and interaction. Enough background to show context but focused on the character. The workhorse of storytelling. |
| **Distance** | Medium — character fills approx 40–50% of frame height |
| **When to Use** | Dialogue, teaching moments, character interaction, everyday activities, most storytelling |
| **Prompt Template** | `medium shot, character from waist up, balanced view, character and environment, standard storytelling shot, friendly framing, warm medium shot, dialogue ready, character focus with context` |

```
    ┌──────────────┐
    │              │
    │    ┌──┐      │
    │    │  │      │
    │    │  │      │  ← Character waist up
    │    └──┘      │
    │   /    \     │
    └──────────────┘
```

## Close-Up

| Field | Description |
|-------|-------------|
| **Description** | The character's face fills most of the frame. Captures emotions, reactions, and expressions. Creates intimacy and connection. The viewer sees exactly what the character feels. |
| **Distance** | Close — face fills approx 60–80% of frame height |
| **When to Use** | Emotional moments, reactions, laughter, surprise, discovery, important lines, showing feelings |
| **Prompt Template** | `close up shot, character face filling frame, emotional expression, intimate view, facial detail, warm close up, emotional connection, character feelings, reaction shot, gentle close framing` |

```
    ┌──────────────┐
    │              │
    │   ┌────┐     │
    │   │ ●  │     │  ← Face fills most of frame
    │   │ ●  │     │
    │   └────┘     │
    │              │
    └──────────────┘
```

## Extreme Close-Up

| Field | Description |
|-------|-------------|
| **Description** | Focuses on a specific detail — eyes, mouth, hands, or an object. Enlarges something small to emphasize its importance. Used sparingly for emphasis or discovery. |
| **Distance** | Very close — only a specific feature or object fills the frame |
| **When to Use** | Showing a character's eyes light up, a special object, a detail in a drawing, hands doing careful work, emphasizing an important prop |
| **Prompt Template** | `extreme close up, detail focus, specific feature enlarged, emphasizing small detail, macro view, intimate detail shot, close detail emphasis, discovery moment, careful observation, tiny detail revealed` |

```
    ┌──────────────┐
    │              │
    │      ◉       │  ← Only the eye or
    │              │     specific detail
    │              │
    │              │
    └──────────────┘
```

## Overhead

| Field | Description |
|-------|-------------|
| **Description** | The camera looks straight down from above. Perfect for table activities, cooking, drawing, games, and crafts. Shows the full layout of a workspace or play area. |
| **Distance** | Variable — typically 3–6 feet above the scene |
| **When to Use** | Cooking/baking scenes, drawing/coloring, board games, puzzles, building blocks, arranging items on a table |
| **Prompt Template** | `overhead shot, top down view, birds eye table view, looking straight down, activity layout view, cooking top view, craft project above, game board view, table scene overhead, activity focused top down` |

```
        Camera
          ↓
    ┌──────────────┐
    │  🥕 🥕       │
    │  🥄 🥣 🌾    │  ← Table/workspace from above
    │  📖 ●        │
    └──────────────┘
```

## Tracking Shot

| Field | Description |
|-------|-------------|
| **Description** | The camera moves alongside the character as they walk, run, or ride. Keeps the character in frame while showing the environment moving past. Creates energy and momentum. |
| **Distance** | Medium — typically a medium or full-body shot that moves with the character |
| **When to Use** | Walking to school, running in the park, riding a bike, exploring a new area, parade scenes |
| **Prompt Template** | `tracking shot, camera following character, moving alongside, dynamic movement shot, character in motion, environment moving past, smooth tracking movement, walking alongside, energetic follow shot, motion shot` |

```
    ──>  Camera moves →
    
    ┌─────────────────────┐
    │                     │
    │  ●  ───────────>    │  ← Character moves, camera follows
    │                     │
    │  🌳  🏠  🌳         │  ← Background moves past
    └─────────────────────┘
```

## Walking Follow (Behind Character)

| Field | Description |
|-------|-------------|
| **Description** | The camera follows behind the character, seeing over their shoulder. Like the viewer is walking with or behind them. Creates a gentle POV-lite feeling. Great for exploration. |
| **Distance** | Medium-close — just behind the character (shoulder/back of head visible) |
| **When to Use** | Entering a new room, walking into school, exploring a new place, following a guide, adventure scenes |
| **Prompt Template** | `walking follow shot, behind character view, over shoulder angle, following perspective, exploring together, gentle POV style, character back visible, walking into scene, exploration shot, adventure follow` |

```
    ┌─────────────────┐
    │                 │
    │   ┌────┐        │  ← Back of character's head
    │   │    │        │
    │   └────┘        │
    │    /  \         │
    │                 │
    │  [Scene ahead]  │  ← What character sees ahead
    └─────────────────┘
                  ↑
               Camera
```

## Front / Side / Rear Angles

| Field | Description |
|-------|-------------|
| **Description** | The camera perspective relative to the character's orientation. **Front**: character faces camera (direct engagement). **Side**: character profile (observational). **Rear**: character faces away (following, departure). |
| **Distance** | Variable — can be any distance depending on needs |
| **When to Use** | **Front**: introductions, direct address, emotional connection. **Side**: walking scenes, side-by-side conversations, showing action. **Rear**: leaving a scene, walking away, following into a new area. |
| **Prompt Template** | `[front/side/rear] angle shot, character [facing camera / in profile / walking away], [direct engagement / observational view / departure shot], clean character view, storytelling angle, standard character framing` |

```
    Front:           Side:           Rear:
    ┌──────┐        ┌──────┐        ┌──────┐
    │ ●    │        │   ●  │        │      │
    │  |   │        │  / \ │        │ ● |  │
    │ / \  │        │      │        │  / \ │
    └──────┘        └──────┘        └──────┘
    Camera          Camera          Camera
    in front        to side         behind
```
