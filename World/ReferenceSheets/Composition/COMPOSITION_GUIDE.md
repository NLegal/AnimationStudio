# Composition Guide

## Design Philosophy

Composition in Little Learning Town should always be **clear, balanced, and easy to read**. Young children should instantly understand where to look. Use composition to guide attention, create visual interest, and support storytelling without confusion.

---

## Rule of Thirds

| Field | Description |
|-------|-------------|
| **Description** | The frame is divided into a 3x3 grid (two horizontal, two vertical lines). Key subjects are placed along these lines or at their intersections. The most fundamental and versatile composition technique. |
| **When to Use** | General storytelling, character interaction, landscape shots, any scene needing natural visual balance |
| **Example** | A character stands at the left third of the frame, looking right into the open space. The horizon sits on the bottom horizontal line. |

```
    ┌────┬────┬────┐
    │    │    │    │
    ├────┼────┼────┤
    │    │ ●  │    │  ● = Subject at intersection
    ├────┼────┼────┤
    │    │    │    │
    └────┴────┴────┘
```

---

## Leading Lines

| Field | Description |
|-------|-------------|
| **Description** | Natural lines in the scene that guide the viewer's eye toward the main subject. Roads, fences, pathways, tree lines, and rivers all work as leading lines. Creates depth and direction. |
| **When to Use** | Introducing a location, showing a path, guiding attention to a character or object, establishing shots |
| **Example** | A winding path starts at the bottom corner and leads to the school building in the distance. The viewer's eye naturally follows the path. |

```
    \          /
     \    ●   /     ● = Subject
      \      /      Lines = Path/road
       \    /
        \  /
```

## Framing (Natural Frames)

| Field | Description |
|-------|-------------|
| **Description** | Elements in the foreground create a "frame" around the subject. Tree branches, doorways, windows, arches, and flower bushes all work as frames. Adds depth and focuses attention. |
| **When to Use** | Cozy scenes, looking into a space, spying on (in a friendly way), introducing a room, making scenes feel immersive |
| **Example** | We look through a window frame at a child reading inside. The window border frames the subject naturally. |

```
    ┌──────────┐
    │ ┌──────┐ │
    │ │  ●   │ │     Outer border = Window/doorway frame
    │ └──────┘ │     ● = Subject inside
    └──────────┘
```

## Centered Composition

| Field | Description |
|-------|-------------|
| **Description** | The subject is placed directly in the center of the frame. Symmetrical and bold. Very direct and clear. Used for character introductions, important moments, and when you want no ambiguity. |
| **When to Use** | Character introductions, important announcements, emotional moments, symmetrical buildings, product shots |
| **Example** | A character stands center frame, looking directly at the camera, with a clean background. All attention is on them. |

```
    ┌──────────────┐
    │              │
    │      ●       │  ● = Subject centered
    │              │
    └──────────────┘
```

---

## Balanced Composition

| Field | Description |
|-------|-------------|
| **Description** | Visual weight is distributed evenly across the frame. If a character is on one side, something of similar visual weight is on the other. Creates harmony and stability. |
| **When to Use** | Group scenes, before/after comparisons, scenes with two characters, establishing shots with multiple points of interest |
| **Example** | A child on the left balances a tree on the right. Or two children, one on each side of the frame. |

```
    ┌──────────────┐
    │              │
    │ ●         ▲  │  ● = Character, ▲ = Object/tree
    │              │
    └──────────────┘
```

## Depth Creation (Foreground, Midground, Background)

| Field | Description |
|-------|-------------|
| **Description** | The scene is composed with three distinct layers. Foreground elements close to camera, midground with main action, and background setting the environment. Creates a rich, immersive feel. |
| **When to Use** | Crowded scenes, outdoor landscapes, room interiors, any scene needing a rich sense of space |
| **Example** | Foreground: flowers and a fence. Midground: children playing. Background: the school building and mountains. |

```
    ┌─────────────────────┐
    │  Background         │ ← Mountains, sky, far buildings
    │    ─────────        │
    │  Midground          │ ← Main subject / action
    │     ●  ●            │
    │  Foreground         │ ← Flowers, fence, near objects
    │  ~~~ ~~~            │
    └─────────────────────┘
```

### Depth Tips
- **Foreground**: Use slightly darker or softer elements to keep focus on midground
- **Midground**: Place the main subject here — brightest, sharpest, most detailed
- **Background**: Keep simpler and lighter, with atmospheric perspective (lighter colors, less detail in distance)
- **Overlap**: Elements should overlap between layers to create a sense of real space
