# Learning Objective Engine Guide

## Purpose

The Learning Objective Engine ensures every episode teaches **exactly one primary concept**. One lesson. One focus. One outcome. This guarantees that each episode has a clear educational purpose and that children can absorb the target concept without distraction.

## Difficulty Levels

| Level | Label | Description |
|---|---|---|
| 1 | Beginner | Simple recognition, single words, concrete objects |
| 2 | Early Learner | Basic identification, simple actions, guided practice |
| 3 | Developing | Concept application, simple reasoning, less guidance |
| 4 | Intermediate | Understanding, prediction, multiple examples |
| 5 | Advanced | Explanation, connection between concepts, independent thinking |

Difficulty scales with age and episode number within a curriculum area. Early episodes at difficulty 1 build foundation; later episodes at difficulty 4-5 deepen understanding.
