# Interaction, Emotion & Humor Guide

## Purpose

The Interaction Engine adds audience participation. The Emotion Engine controls the emotional flow. The Humor Engine creates age-appropriate laughter. Together, they transform a passive viewing experience into an engaging, emotionally resonant, and joyful learning journey.

---

## Interaction Engine

### What It Does

The Interaction Engine plans moments when the audience is invited to participate actively. These moments are strategically placed to reinforce learning, maintain engagement, and build the habit of active viewing.

### Interactive Moment Types

| Type | Description | Example | Best Placement |
|---|---|---|---|
| **Count Along** | Count objects together | "Let's count the ducks! One, two, three!" | Teaching / Practice |
| **Say the Word** | Repeat a key vocabulary word | "Say 'triangle' with me!" | Teaching |
| **Point / Show** | Physical gesture response | "Can you point to something red?" | Practice |
| **Clap / Stomp** | Rhythmic physical response | "Clap three times!" | Celebration |
| **Answer a Question** | Simple verbal response | "What color is this?" | Discovery |
| **Find Something** | Visual search | "Can you find the bunny?" | Exploration |
| **Make a Sound** | Animal or environmental sounds | "Can you roar like a lion?" | Activity |
| **Follow a Motion** | Physical movement | "Wiggle your fingers like this!" | Song / Dance |
| **Echo Repeat** | Repeat a phrase back | "Say 'thank you' like Lily!" | Social lesson |
| **Choice Question** | Simple binary choice | "Do you like the red one or the blue one?" | Engagement |
| **Predict** | Guess what happens next | "What do you think will happen?" | Problem solving |
| **Celebration Together** | Shared cheer | "Hooray! Can you cheer too?" | Success / End |

### Interaction Timing Guidelines

- **Pause for 2-3 seconds** after each interactive prompt
- Place interactions **after the concept is introduced** (not before)
- **Maximum 3-4 interactions** per minute for ages 2-3
- **Maximum 4-5 interactions** per minute for ages 4-6
- Place at least **one interaction in every scene**
- End every episode with **one final interactive moment**

### Interaction Placement in Standard Framework

```
Opening     → "Say hello to Lily!"
Goal        → "What do you think Lily wants?"
Problem     → "Oh no! Can you help find it?"
Discovery   → "What did they find?"
Learning    → "Say 'blue' with me!"
Practice    → "Can you count to four?"
Success     → "Clap for Lily!"
Celebration → "Dance with us!"
Goodbye     → "Wave goodbye!"
```

## Emotion Engine

### What It Does

The Emotion Engine controls the emotional flow of the episode. It ensures children experience a range of positive emotions and that any challenging moments remain mild and quickly resolved.

### Standard Emotional Arc

```
Curiosity
    ↓
Excitement
    ↓
Challenge (mild)
    ↓
Thinking
    ↓
Learning
    ↓
Success
    ↓
Celebration
```

### Scene-by-Scene Emotional Map

| Scene | Emotion | Intensity | Purpose |
|---|---|---|---|
| Opening | Curiosity, Warmth | Medium | Pull children into the story |
| Goal | Excitement, Anticipation | Medium-High | Motivate the episode journey |
| Problem | Concern, Perplexity | Low-Medium | Create mild tension, encourage thinking |
| Discovery | Hope, Realization | Medium | Lightbulb moment |
| Learning | Focus, Engagement | Medium | Core teaching, active attention |
| Practice | Determination, Confidence | Medium-High | Build mastery |
| Success | Pride, Joy | High | Reward for learning |
| Celebration | Joy, Elation | High | Peak emotional moment |
| Goodbye | Contentment, Warmth | Medium | Gentle landing |

### Emotional Rules

| Rule | Explanation |
|---|---|
| No fear | Problems must never be frightening |
| No sadness without resolution | Sad moments must resolve within 30 seconds |
| No emotional extremes | No overwhelming joy or deep distress |
| Emotional arc rises overall | Episode ends happier than it began |
| Negative emotions are brief | Max 15-20 seconds of mild concern |
| Every emotion is named | "You look sad," "I feel happy!" |
| Emotions connect to learning | "Learning makes me happy!" |

### Age-Appropriate Emotional Complexity

| Age | Emotional Vocabulary | Complexity |
|---|---|---|
| 2-3 | happy, sad, mad, scared | Basic identification |
| 3-4 | surprised, silly, proud, shy | Extended vocabulary |
| 4-5 | frustrated, excited, grateful, nervous | Nuanced emotions |
| 5-6 | disappointed, relieved, embarrassed, confident | Complex emotional states |

## Humor Engine

### What It Does

The Humor Engine adds age-appropriate funny moments that delight children without confusing, embarrassing, or scaring them. Humor is used to:
- Maintain attention
- Create memorable moments
- Make learning joyful
- Build character likability

### Humor Types

| Type | Description | Example | When to Use |
|---|---|---|---|
| **Funny Sneeze** | Character sneezes comically | "Aaa-choo!" *feathers fly everywhere* | Anytime, light mood |
| **Silly Dance** | Character does a goofy move | Ben Bear wiggles his ears | Song / celebration |
| **Goofy Hat** | Character wears something silly | Daisy wears a hat that's too big | Opening / playtime |
| **Animal Hiccup** | Animal character gets hiccups | Duck hiccups in the middle of quacking | Teaching / practice |
| **Ticklish Feathers** | Tickling sensation | Lily Bunny's nose twitches | Exploration |
| **Bubble Surprise** | Unexpected bubbles | Bubbles appear when clapping | Celebration |
| **Gentle Repetition** | Same funny thing repeated | Ben Bear keeps saying "blue" to everything | Practice / reinforcement |
| **Silly Mix-up** | Character confuses something obvious | Ben Bear tries to wear a bucket as a hat | Problem / discovery |
| **Funny Sound** | Comical sound effects | Boing! Pop! Squish! | Transitions |
| **Playful Fall** | Soft, safe tumble | *trips over a block, lands on a pillow* | Playtime |

### Humor Rules

| Rule | Explanation |
|---|---|
| Never embarrass a character | Humor should be warm, not mocking |
| No physical pain | Falls must be soft, never hurtful |
| No mean-spirited jokes | No teasing or exclusion |
| No potty humor | Bathroom themes are educational, not comedic |
| Keep it simple | Children under 6 understand physical humor best |
| Use repetition | Kids laugh at familiar funny moments |
| Connect to learning | "Silly counting" — count with funny voices |

### Humor Placement

| Episode Phase | Best Humor Type |
|---|---|
| Opening | Goofy hat, silly dance |
| Goal | Funny sound, silly expression |
| Problem | Gentle mix-up, playful fall |
| Discovery | Bubble surprise, ticklish moment |
| Learning | Funny sneeze, gentle repetition |
| Practice | Animal hiccup, silly counting voice |
| Success | Silly dance, celebration pop |
| Goodbye | Final funny sound, wave with silly motion |

### Humor + Emotion Integration

```
Humor should:
- Lift emotional lows (a funny moment during "thinking")
- Enhance emotional highs (a silly dance during celebration)
- Never undercut learning (no jokes during core teaching)
- Never mock the educational objective (always respect the lesson)
```
