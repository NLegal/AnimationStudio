# Theme Engine Guide

## Purpose

The Theme Engine selects the episode theme. The theme supports the learning objective but does not replace it. A theme provides the narrative context that makes the educational content engaging and relatable for young children.

## How Themes Support Learning Objectives

The theme should make the learning objective feel natural, not forced.

| Learning Objective | Compatible Themes | Why It Works |
|---|---|---|
| Count to Five | Birthday, Cooking, Grocery Store, Treasure Hunt | Counting candles, ingredients, items, clues |
| Recognize Blue | Rainbow Hunt, Beach, Space Adventure, Kite Flying | Blue sky, ocean, planet, blue kite |
| Identify Triangles | Building Blocks, School, Treasure Hunt | Block shapes, classroom shapes, flag shapes |
| Brush Teeth | Bath Time, Bedtime, Doctor Visit | Routine-based learning |
| Share Toys | Playground, Birthday, School, Pet Care | Natural sharing situations |
| Learn Duck Sounds | Farm Visit, Zoo, Pet Care, Pond/Spring | Direct animal encounters |
| Sort Shapes | Building Blocks, Grocery Store, Cooking | Organizing by shape naturally |
| Wash Hands | Cooking, Doctor Visit, Grocery Store, Bath Time | Hygiene moments in context |
