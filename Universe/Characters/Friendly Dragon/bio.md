# Friendly Dragon

## Basic Information
- **Name:** Friendly Dragon
- **Nickname:** Friend
- **Species:** Dragon
- **Gender:** Male
- **Age:** Ageless
- **Favorite Color:** Green (`#7EC850`)
- **Favorite Food:** Sparkle berries
- **Favorite Activity:** Guarding playgrounds, blowing bubbles
- **Favorite Game:** Fetch (with bubble balls)
- **Favorite Season:** Spring
- **Favorite Weather:** Rainy (makes more bubbles)
- **Weight:** 200 kg

## Appearance
- **Scale Color:** Mint green (`#A8E6CF`)
- **Belly Scales:** Golden yellow (`#F5D442`)
- **Eye Color:** Big round purple (`#C8A0D0`)
- **Horn Color:** Soft brown, small
- **Wings:** Tiny — too small to fly properly, translucent with mint veins
- **Tail:** Long with spade tip (golden)
- **Body Shape:** Round, soft, huggable proportions
- **Face Shape:** Gentle, broad snout
- **Nose:** Small rounded nostrils
- **Mouth:** Wide friendly smile
- **Eyebrows:** Soft expressive arches
- **Eyelashes:** Visible, kind
- **Teeth:** None visible (no fire teeth)
- **Scales Pattern:** Smooth, overlapping mint green
- **Underbelly:** Cream (`#FFF5E6`)
- **Claws:** Small, rounded, golden
- **Accessories:** None

## Forms / States
| Variant | Description |
|---------|-------------|
| Resting | Sitting, tail curled around body, wings folded |
| Flying | Wings spread wide, struggling but happy, bubble trail |
| Playing | Prancing, blowing bubble rings, tail wagging |
| Guarding | Sitting tall, proud posture, gentle watchful eyes |
| Sleeping | Curled up in a ball, wings covering face, gentle snoring bubbles |
| Excited | Hopping, wings fluttering, bubbles streaming from nose |
| Hugging | Wrapping tail and arms around friend, eyes closed peacefully |

## Personality
- **Primary:** Gentle, Protective, Playful
- **Secondary:** Kind, Patient, Brave
- **Tertiary:** Shy about wings, Eager to help, Easily excited

## Skills
- Bubble blowing (sparkling, rainbow-tinted)
- Warm hugs (naturally warm body temperature)
- Flying (poorly — low altitude, short distances)
- Guarding playgrounds
- Gentle play with small creatures
- Napping in sunbeams

## Weaknesses
- Can't breathe fire (only bubbles)
- Embarrassed about tiny wings
- Too large for indoor games
- Bump into things with tail
- Gets sad when mistaken for scary

## Catchphrases
1. "Magic is for helping!"
2. "Don't worry, I'm a friendly dragon!"
3. "Watch this bubble!"
4. "Want a hug?"
5. "I'll keep you safe."
