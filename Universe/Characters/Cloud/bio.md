# Cloud

## Basic Information
- **Name:** Cloud
- **Nickname:** Fluff
- **Species:** Cloud
- **Gender:** Neutral (they/them)
- **Age:** Ageless
- **Favorite Color:** White/cream (`#FFF5E6`)
- **Favorite Food:** Sunbeams
- **Favorite Activity:** Shape-shifting, storytelling
- **Favorite Game:** "What shape am I now?"
- **Favorite Season:** Spring (mild breezes)
- **Favorite Weather:** Sunny with a light breeze

## Appearance
- **Color:** Soft white, cream undertones
- **Edges:** Sometimes rainbow-tinted (inner glow)
- **Face:** Smiling face visible in the cloud fluff
- **Body Shape:** Puffy, round, ever-changing
- **Eyes:** Soft, gentle, dark (like shadow)
- **Mouth:** Simple curve, kind smile
- **Texture:** Fluffy, soft-edged
- **Size:** Medium (can grow or shrink)
- **Accessories:** None — changes form instead

## Forms / States
| Variant | Description |
|---------|-------------|
| Puffy | Classic rounded cloud, smiling |
| Storyteller | Shifting shapes — bunny, heart, tree, dragon |
| Rain | Sad — gray edges, gentle drizzle |
| Sunset | Painted pink and orange by Sun |
| Rainbow Friend | Holding Rainbow in the sky |
| Sleeping | Slow drifting, face relaxed, soft edges |
| Playful | Quick shape changes, game of "guess me" |
| Protective | Broader, shielding below from harsh sun |

## Personality
- **Primary:** Dreamy, Creative, Gentle
- **Secondary:** Storyteller, Soothing, Playful
- **Tertiary:** Emotional (weather reflects mood), Wise, Patient

## Skills
- Shape-shifting (tells stories in the sky)
- Storytelling (creates pictures from shapes)
- Gentle rain (soft, warm drizzle)
- Making shade (protects friends)
- Floating gracefully
- Reflecting sunset colors

## Weaknesses
- Blows away in strong wind
- Melts when too sad (cries rain)
- Can't stay still easily
- Fades at night (becomes invisible)
- Can't hold objects (fluffy)

## Catchphrases
1. "Let's float together!"
2. "What shape do you see?"
3. "I'll be your shade."
4. "Shhh... listen to the breeze."
5. "Every cloud has a story."

## Relationships
| Name | Relationship | Notes |
|------|-------------|-------|
| Sun | Sky Friend | Best daytime companion, sunrise-and-set |
| Rainbow | Sky Friend | Needs Cloud and Sun to appear |
| Moon | Night Friend | Cloud visits Moon at night |
| Friendly Dragon | Friend | Carries Dragon for sky rides |
| Alien | Friend | Floating together, exploring skies |
| Stars | Friend | Cloud parts to reveal them at night |

## Emotion Matrix
| Situation | Reaction |
|-----------|----------|
| Happy | Fluffier, whiter, sun edges |
| Sad | Gray tinge, soft rain falling |
| Telling a story | Shifts shape slowly, dramatic pauses |
| Strong wind | Nervous — stretches thin, grips sky |
| Sunset time | Blushes pink and orange |
| Playing with friends | Bounces, quick shape changes |
| A friend is sad | Hovers close, offers gentle shade |
| Nighttime | Fades slowly, whispers goodnight |
| Seeing a rainbow | Brightens, edges glow colorful |
| Making a new friend | Softens shape, warm smile, gentle floating |
