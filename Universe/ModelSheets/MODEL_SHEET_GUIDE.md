# Model Sheets — Guide

> **Version:** 1.0
> **Purpose:** Technical reference for consistent character reproduction

## What is a Model Sheet?

A model sheet is a technical document that defines exactly how a character looks, proportioned, and colored. It ensures every artist and AI model produces the same character.

## Model Sheet Structure

Each model sheet contains:

### 1. Proportion Diagram
- Total height in head units (standard: 3-4 heads tall for child characters)
- Head width-to-height ratio (standard: 1:1.2)
- Eye position (standard: midpoint of head)
- Body segment ratios (torso:legs = 1:1 for toddlers)

### 2. Construction Breakdown
- Head: sphere + jaw block
- Body: rounded cylinder
- Arms: 3-segment tubes
- Legs: 2-segment tubes
- Hands: rounded mitts with finger hints
- Feet: oversized rounded ovals

### 3. Color Specification
- Exact hex codes for every surface
- Material finish (matte/slightly glossy)
- Shadow tint percentages

### 4. Size Reference

| Part | Ratio (relative to head) |
|------|--------------------------|
| Head | 1.0x |
| Torso | 1.2x |
| Arm length | 1.5x |
| Leg length | 1.5x |
| Foot length | 0.4x |
| Hand size | 0.3x |
| Eye width | 0.2x |
| Eye height | 0.15x |

### 5. Turnaround Measurements
- Front: full width/height
- Side: depth (should be 60% of front width)
- Back: same as front

## Universal Standards

All characters share:
- 3-4 heads tall (preschool proportion)
- Head: body ratio = 1:1.8
- Eyes at vertical midpoint of head
- Eye spacing = 1 eye width apart
- Mouth at 25% from bottom of head
- Hands = 80% of foot length

## AI Generation Notes

For AI model generation, these proportions should be encoded in the prompt:
"Cocomelon-inspired character, 3 heads tall, large round head, oversized eyes, small nose, simple mouth, rounded body, soft pillowy limbs, preschool proportions, Pixar-quality"
