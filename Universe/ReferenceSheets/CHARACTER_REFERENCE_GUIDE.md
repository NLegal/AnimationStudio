# Character Reference Sheets — Guide

> **Version:** 1.0
> **Purpose:** Standard template for every character reference sheet

## Reference Sheet Contents

Every character requires a reference sheet containing:

### 1. Identity Panel
- Full body front view
- Character name + species
- Signature color swatch
- Height marker (relative to Lily Bunny)

### 2. Turnaround
- Front (0°)
- Three-quarter (45°)
- Profile (90°)
- Three-quarter back (135°)
- Back (180°)
- Top view (head only)

### 3. Expression Sheet
- 12 core expressions per character:
  - Neutral, Happy, Very Happy, Excited
  - Surprised, Curious, Thinking
  - Sleepy, Sad, Scared
  - Proud, Singing

### 4. Pose Sheet
- 8 core poses per character:
  - Standing, Walking, Jumping
  - Sitting, Waving, Pointing
  - Clapping, Dancing

### 5. Outfit Sheet
- Daily outfit (primary)
- Seasonal variants (summer/winter)
- Special occasion (birthday/holiday)

### 6. Scale Reference
- Height comparison to standard door (2m)
- Height comparison to other main characters

## Character-Specific Reference Notes

### Lily Bunny
- Blue bow always visible in every angle
- Cotton tail visible from back and ¾-back
- Pink inner ear visible from front at certain angles

### Ben Bear
- Blue overalls straps visible in front and back
- Round teddy bear ears visible from all angles
- Paws lighter brown than body fur

### Charlie Fox
- Orange fur with white chest/tail tip
- Pointed ears visible in all profiles
- Bushy tail with white tip

### Daisy Duck
- Yellow bill visible from all front angles
- Purple bow on head
- Webbed feet visible from low angles

## Generation Notes
- Reference sheets require image generation (ComfyUI)
- Each character needs ~30 reference images total
- Maintain consistent lighting across all sheets
- Use white or neutral background for turnaround
