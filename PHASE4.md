# Phase 4 — Animation Bible & Motion System

## AI Nursery Studio

### Version 1.0

---

# Objective

Characters, environments, and assets are now complete.

Phase 4 defines **how everything moves**.

This phase establishes the visual language of your studio by standardizing movement, facial acting, timing, camera behavior, and physical interactions. Every future animation should follow these rules to maintain a recognizable style.

---

# End Goal

By the end of Phase 4 you should have:

* Complete animation style guide
* Motion standards
* Facial animation library
* Body animation library
* Hand gesture library
* Walk and run cycles
* Dance library
* Camera language
* Scene transition rules
* Physics rules
* Interaction standards
* Prompt templates for animation
* Quality-control checklist

---

# Animation Philosophy

Movement should feel:

* Playful
* Soft
* Rounded
* Energetic
* Safe
* Readable
* Slightly exaggerated
* Easy for young children to follow

Avoid fast, jerky, or chaotic motion.

---

# Frame Rate

Master animation at:

* 24 fps (cinematic)
* Export at 30 fps if required by the platform

Keep motion smooth and consistent.

---

# Character Motion Principles

Every character should have:

* Idle animation
* Walk cycle
* Run cycle
* Jump cycle
* Sit cycle
* Stand cycle
* Dance loop
* Wave loop
* Clap loop
* Hug loop
* Pointing loop
* Reading loop
* Sleeping loop
* Singing loop

These become reusable building blocks.

---

# Idle Animation

Characters should never appear frozen.

Include subtle:

* Breathing
* Eye blinking
* Head sway
* Gentle body weight shifts
* Ear, bow, or tail movement (where applicable)

---

# Facial Animation Library

Standardize:

* Smile levels
* Eye openness
* Eyebrow positions
* Lip shapes
* Laugh expressions
* Cry expressions
* Surprise
* Curiosity
* Thinking
* Excitement

Each emotion should have a defined intensity scale (e.g., 1–5).

---

# Eye Animation

Eyes are the focal point.

Define:

* Blink frequency
* Blink duration
* Eye tracking
* Eye contact rules
* Looking at speaking characters
* Looking toward objects before reaching for them

---

# Mouth Animation

Support:

* Talking
* Singing
* Laughing
* Yawning
* Whispering
* Breathing

Use clear, exaggerated mouth shapes suitable for preschool audiences.

# Object Physics

Use stylized physics.

Objects should:

* Feel light
* Move predictably
* Bounce softly when appropriate
* Never behave violently

Maintain child-friendly motion over realism.

---

# Cloth & Accessory Motion

Define secondary motion:

* Dresses sway
* Bows bounce
* Tails follow movement
* Scarves flutter
* Balloons float gently

These details add life without distracting from the main action.

---

# Camera Language

Standardize camera shots.

* Establishing shot
* Wide shot
* Medium shot
* Close-up
* Over-the-shoulder
* Tracking shot
* Slow push-in
* Gentle pan
* Gentle tilt

Avoid rapid zooms or shaky movement.

---

# Scene Transitions

Use a consistent transition library.

* Cross dissolve
* Fade
* Wipe
* Match cut
* Storybook page turn (optional)
* Gentle slide

Avoid flashy effects that distract from the story.

---

# Timing

Use slower pacing than content for adults.

Allow children time to:

* Observe
* Recognize objects
* Read subtitles
* Follow lyrics
* Understand actions
