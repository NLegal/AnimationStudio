# Font Guide

> **Version:** 1.0
> **Style:** Child-friendly, rounded, readable
> **Principle:** Fonts should be as warm and approachable as the visuals

## Title Font

| Property | Value |
|----------|-------|
| Font | Fredoka One (or similar rounded sans-serif) |
| Weight | Semi-Bold |
| Size | 48–72pt for titles |
| Letter Spacing | +2px |
| Color | White or Primary Palette |

Use for: Episode titles, character name cards, title cards

## Body Font

| Property | Value |
|----------|-------|
| Font | Nunito (or similar rounded sans-serif) |
| Weight | Regular (400) |
| Size | 24–36pt for subtitles |
| Line Height | 1.5 |
| Color | White with 4px black outline (readability) |

Use for: Subtitles, lyric overlays, educational text

## Decorative Font

| Property | Value |
|----------|-------|
| Font | Baloo 2 (or similar playful rounded) |
| Weight | Medium (500) |
| Size | 36–60pt |
| Color | Matches episode theme |

Use for: Special lyrics, celebration text, holiday titles

## Subtitle Standards

- Line length: max 40 characters
- Max lines: 2
- Display duration: 3–5 seconds per line
- Outline: 4px black with white fill
- Position: Bottom-center, 10% from bottom edge
- Font: Nunito Bold, 28pt

## Font Files

Font files should be placed in this directory. Recommended sources:
- Google Fonts (free, open-source)
- Font Squirrel (free for commercial)

Required font files:
- FredokaOne-Regular.ttf
- Nunito-Regular.ttf
- Nunito-Bold.ttf
- Baloo2-Medium.ttf
