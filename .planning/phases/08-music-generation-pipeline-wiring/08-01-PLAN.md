## Hard Constraints (non-negotiable, echo in every commit)

- **C1** — No visual-asset generation anywhere in this phase; no real audio generated in CI/tests (MockBackend only; the ONLY real-audio moment remains the documented manual live smoke).
- **C2** — The repo-root asset-catalog SQLite database (`catalog.db`) is NEVER opened, written, or imported by this phase's code or tests; all song artifacts live on disk under the music output directory with their JSON manifest — grep-gated plus byte-identity check (Phase 7 precedent).

- **C4** — Report mode of `scripts/generate_phase5.py` stays byte-compatible: without `--generate` behavior is identical to today (the Colab notebook and PHASE5_STATUS Reproduction block depend on it). Generation mode is orthogonal — it never rewrites PHASE5_REPORT.md as a side effect.
- **C5** — Suno stays a NotConfigured stub: selecting it via CLI surfaces a typed error message and exit 1, never an HTTP 500-style traceback spill.
- **C6** — Zero new dependencies: stdlib only; `pyproject.toml` untouched (grep-gate).
