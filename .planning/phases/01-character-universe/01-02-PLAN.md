<objective>
Implement all 7 scoring plugins for the Identity Engine per D-06 weighted scoring pipeline, plus the diversity filter for deduplication. Each plugin follows the `ScoringPlugin` protocol (name, weight, score()) established in Plan 01-01.

**Purpose:** The Identity Engine is the quality gate for all generated assets — every image must pass through scoring before human review. The 7 sub-scores (DINOv2 40%, CLIP 20%, Color 10%, Part 10%, Pose 5%, Expression 5%, Style 10%) produce a Brand Score that determines whether an asset is shortlisted for human review or rejected for regeneration.

**Output:** Runnable scoring plugins that accept a PIL Image and optional reference, returning normalized 0-1 scores. Tests verify all plugins, weight distribution, and edge cases.
</objective>

    - Lazy-loads DINOv2 model via `torch.hub.load('facebookresearch/dinov2', 'dinov2_vits14')` on first use (not on init — tolerate missing torch.hub cache)

    - `embed(image: Image.Image) -> torch.Tensor`: resizes to 224, center crops, normalizes per ImageNet stats, returns 384-dim embedding

    - Uses `torch.nn.functional.cosine_similarity` for comparison

    - Returns normalized score based on how many dominant colors fall within allowed palette
