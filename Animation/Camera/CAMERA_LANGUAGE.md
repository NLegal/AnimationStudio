# Camera Language Guide

## Version 1.0 — AI Nursery Studio

---

## Introduction

The camera at AI Nursery Studio is a **storyteller, not a distraction**. Every choice — shot size, angle, movement, duration — serves the narrative and helps preschool audiences follow the action.

**Core Principles:**
- Camera is always steady and intentional
- Movement is gentle, slow, and motivated
- The camera prioritizes what children need to see
- Transitions are smooth and predictable
- Children should never feel disoriented

**Frame Rate:** All durations assume 24 fps.

---

## Shot Library

---

### Establishing Shot

| Property | Specification |
|----------|---------------|
| **Description** | Full location view establishing where the scene takes place |
| **Frame Composition** | Wide view, characters are small (<20% of frame), environment dominates |
| **Distance** | Very far — full room, playground, outdoor area |
| **When to Use** | Opening a new scene, location change, time of day transition |
| **Duration** | 3-5 seconds (72-120 frames) |
| **Movement** | Static or very slow gentle pan (1-2° per second) |
| **Camera Height** | Average character eye level |

**Composition Example:**
```
┌──────────────────────────────┐
│                              │
│  🌳🏠                ☁️☁️   │
│                              │
│        🐰 (tiny)            │
│    ─────── ground ───────   │
└──────────────────────────────┘
```

**Notes:**
- Use 1 per scene, at the start
- Pair with ambient sound or narrator intro
- Environment fills 80%+ of frame

---

### Wide Shot

| Property | Specification |
|----------|---------------|
| **Description** | Character visible within their environment during action |
| **Frame Composition** | Full body visible, character occupies 30-40% of frame height |
| **Distance** | Far — shows character and immediate surroundings |
| **When to Use** | Walking, playing, interacting with objects, showing context |
| **Duration** | 2-4 seconds (48-96 frames) |
| **Movement** | Static or smooth tracking with character |
| **Camera Height** | Character eye level |

**Composition Example:**
```
┌──────────────────────────────┐
│                              │
│       🐰 (full body)        │
│                              │
│   ───────── floor ────────  │
└──────────────────────────────┘
```

**Notes:**
- Standard action shot
- Character has room to move within frame
- Background shows relevant context

---

### Medium Shot

| Property | Specification |
|----------|---------------|
| **Description** | Character from waist up, primary dialogue/expression shot |
| **Frame Composition** | Character centered or on rule-of-thirds, hands visible for gestures |
| **Distance** | Medium — character fills 50-60% of frame width |
| **When to Use** | Conversation, emotional beats, showing reactions, gestures |
| **Duration** | 2-6 seconds (48-144 frames) |
| **Movement** | Static preferred; micro-adjustments allowed (2-3 pixels) |
| **Camera Height** | Eye level |

**Composition Example:**
```
┌──────────────────────────────┐
│                              │
│       ┌──────┐              │
│       │ 🐰  │               │
│       │face  │              │
│       └──────┘              │
│       (hands visible)       │
└──────────────────────────────┘
```

**Notes:**
- Most frequently used shot type
- Hands visible for gesture readability
- Background is visible but secondary

---

### Close-Up

| Property | Specification |
|----------|---------------|
| **Description** | Face fills frame, emphasizes emotion |
| **Frame Composition** | Face centered, minimal background visible |
| **Distance** | Close — face fills 70-80% of frame |
| **When to Use** | Emotional moments, reaction shots, important expressions |
| **Duration** | 1-4 seconds (24-96 frames) |
| **Movement** | Static only |
| **Camera Height** | Eye level |

**Composition Example:**
```
┌──────────────────────────────┐
│                              │
│       ┌────────┐            │
│       │ 🐰   │             │
│       │ face   │            │
│       │ only   │            │
│       └────────┘            │
│                              │
└──────────────────────────────┘
```

**Rules:**
- Use sparingly — no more than 2 per scene
- Always establish with wider shot first
- Minimum hold: 24 frames (1 second)
- Eyes should be in upper third of frame
- Expression must read clearly

---

### Over-the-Shoulder (OTS)

| Property | Specification |
|----------|---------------|
| **Description** | Shot from behind one character, facing the other |
| **Frame Composition** | Back of foreground character's head/shoulder (25-30% of frame) on left or right; background character in remaining space |
| **Distance** | Foreground: close; background: medium |
| **When to Use** | Dialogue between two characters |
| **Duration** | 2-4 seconds (48-96 frames) |
| **Movement** | Static |
| **Camera Height** | Eye level of speaking character |

**Composition Example:**
```
┌──────────────────────────────┐
│  🐰🧏→      🐱              │
│  back of     facing          │
│  head        character       │
│  (30%)       (70%)           │
└──────────────────────────────┘
```

**Rules:**
- Foreground character is slightly out of focus (shallow depth of field)
- At least one ear/top of head visible for character recognition
- Switch sides between speakers in back-and-forth dialogue
- Avoid during fast-paced action

---

### Tracking Shot

| Property | Specification |
|----------|---------------|
| **Description** | Camera follows character moving through environment |
| **Frame Composition** | Character maintains consistent position while background scrolls |
| **Distance** | Wide or medium |
| **When to Use** | Following character movement (walk, run, explore) |
| **Duration** | 3-8 seconds (72-192 frames) |
| **Movement** | Smooth lateral, forward, or rear tracking |
| **Camera Height** | Character eye level |

**Tracking Types:**
| Type | Description | Best For |
|------|-------------|----------|
| Lateral | Camera moves sideways, parallel to character | Walking, running |
| Forward | Camera moves backward as character approaches | Entering a scene |
| Rear | Camera follows behind character | Exploring, journey |
| Leading | Camera moves ahead, character enters frame | Revealing destination |

**Rules:**
- Camera speed matches character speed exactly
- No speed changes during track
- No camera shake
- Character maintains consistent frame position (left third, center, etc.)

---

### Slow Push-In

| Property | Specification |
|----------|---------------|
| **Description** | Gentle forward camera movement toward subject |
| **Frame Composition** | Starts wider, ends tighter (one shot-size step) |
| **Distance** | Moves from far/medium to medium/close |
| **When to Use** | Emotional revelation, important line, magical moment, building importance |
| **Duration** | 3-5 seconds (72-120 frames) |
| **Movement** | Very slow, even forward dolly; ease-in 6 frames, ease-out 6 frames |

**Push-In Steps:**
| Starting Shot | Ending Shot | Push Duration |
|--------------|-------------|---------------|
| Wide | Medium | 4 seconds (96 frames) |
| Medium | Close-up | 3 seconds (72 frames) |
| Establishing | Wide | 5 seconds (120 frames) |

**Rules:**
- Maximum one push-in per scene
- Never push from wide to extreme close-up (too far)
- Hold final position for 1-2 seconds
- Dolly (camera move) preferred over zoom (lens change)
- Do not push during active action sequences

---

### Gentle Pan

| Property | Specification |
|----------|---------------|
| **Description** | Camera rotates horizontally to scan or reveal environment |
| **Frame Composition** | Continuous horizontal reveal |
| **Distance** | Fixed distance throughout pan |
| **When to Use** | Showing a room, following horizontal movement, revealing scenery |
| **Duration** | 3-6 seconds (72-144 frames) |
| **Movement** | Smooth horizontal rotation with 6-frame ease-in and ease-out |

**Pan Speed:**
| Speed | Degrees/Second | Use Case |
|-------|---------------|----------|
| Slow | 2-3° | Scenic reveal, scanning |
| Medium | 4-6° | Following character |
| Fast (rare) | 8-10° | Surprise reveal |

**Rules:**
- Always ease-in (6 frames) and ease-out (6 frames)
- Maximum pan arc: 180°
- No panning back and forth (cut instead)
- Pan direction follows story logic (left-to-right for forward progress)

---

### Gentle Tilt

| Property | Specification |
|----------|---------------|
| **Description** | Camera rotates vertically to scan or reveal height |
| **Frame Composition** | Continuous vertical reveal |
| **Distance** | Fixed distance throughout tilt |
| **When to Use** | Revealing tall objects, looking up/down, showing scale |
| **Duration** | 3-5 seconds (72-120 frames) |
| **Movement** | Smooth vertical rotation with 6-frame ease-in and ease-out |

**Tilt Speed:**
| Speed | Degrees/Second | Use Case |
|-------|---------------|----------|
| Slow | 2-3° | Revealing tall tree, building |
| Medium | 4-6° | Following character climbing |

**Rules:**
- Always ease-in (6 frames) and ease-out (6 frames)
- Maximum tilt arc: 90°
- Tilt up: start at ground level, end at upper area
- Tilt down: start at height, end at ground level

---

### Two-Shot

| Property | Specification |
|----------|---------------|
| **Description** | Two characters in the same frame |
| **Frame Composition** | Both fully visible, facing each other or both facing camera |
| **Distance** | Medium — combined characters fill 60-70% of frame width |
| **When to Use** | Two characters interacting, side-by-side activities |
| **Duration** | 2-6 seconds (48-144 frames) |
| **Movement** | Static |
| **Camera Height** | Eye level (or midway between two characters' heights) |

**Composition Options:**
| Arrangement | Description | Best For |
|-------------|-------------|----------|
| Facing | Characters on left and right thirds, facing inward | Conversation |
| Side-by-side | Both facing same direction | Watching, walking together |
| One behind | Depth separation, foreground/background | Teaching, guiding |
| Angle toward | Both angled slightly toward center | Shared focus |

---

### Group Shot

| Property | Specification |
|----------|---------------|
| **Description** | Three or more characters in the same frame |
| **Frame Composition** | All characters fully visible, arranged by group dynamics |
| **Distance** | Wide — group fills 50-70% of frame width |
| **When to Use** | Group activities, classroom scenes, playtime, song numbers |
| **Duration** | 3-6 seconds (72-144 frames) |
| **Movement** | Static or gentle pan |
| **Camera Height** | Average group eye level |

**Arrangement Patterns:**
| Pattern | Description | Use |
|---------|-------------|-----|
| Line | Horizontal row | Classroom, marching |
| Arc | Semicircle around focal point | Story time, group activity |
| Cluster | Grouped around activity | Building blocks, art table |

---

### Insert Shot

| Property | Specification |
|----------|---------------|
| **Description** | Close-up of an object, hands, or specific detail |
| **Frame Composition** | Object or hands fill 80-90% of frame |
| **Distance** | Very close |
| **When to Use** | Showing detail of interaction, highlighting important object |
| **Duration** | 1-3 seconds (24-72 frames) |
| **Movement** | Static or subtle follow of action |

**Examples:**
- Hands opening a book
- Building blocks stacking
- Apple being bitten
- Pencil drawing on paper
- Water pouring from cup
- Flower being planted

**Rules:**
- Always motivated by story need
- Preceded by wider shot establishing context
- Return to previous shot after insert
- Maximum 2 inserts per scene

## Camera Movement Rules

| Movement | Status | Note |
|----------|--------|------|
| Gentle pan | ✅ Allowed | Slow, ease-in/out |
| Gentle tilt | ✅ Allowed | Slow, ease-in/out |
| Lateral track | ✅ Allowed | Smooth, matched to character |
| Forward/back dolly | ✅ Allowed | Slow push-in or pull-out |
| Crane/boom | ✅ Allowed | Slow vertical, rare use |
| Handheld shake | ❌ Never | Disorienting for preschoolers |
| Whip pan | ❌ Never | Too fast |
| Crash zoom | ❌ Never | Too aggressive |
| Dutch angle | ❌ Never | Unsettling |
| Snap zoom | ❌ Never | Too violent |
| 360° orbit | ⚠️ Rarely | Only if >6 seconds, very slow |

## Camera Height Standards

| Subject | Camera Height |
|---------|---------------|
| Standing adult character | Adult eye level |
| Standing child character | Child eye level |
| Sitting character | Seated eye level |
| Floor play | Ground level, slight upward angle |
| Object focus | Center of object |
| Group mixed heights | Average of character eye levels |
| Establishing environment | Eye level of primary character |

**Default Position:** Camera at the eye level of the youngest character in the scene.

## Shot Sequencing

### Standard Scene Opening
```
Establishing Shot (3-4s) → Wide Shot (2-3s) → Medium Shot (3-5s) → continue...
```

### Conversation (Two Characters)
```
Two-Shot (2-3s) → OTS Character A (2-3s) → OTS Character B (2-3s) → repeat
```

### Action Sequence
```
Wide Shot (2-3s) → Tracking Shot (3-5s) → Insert Shot (1-2s) → Wide Shot (2s)
```

### Emotional Beat
```
Medium Shot (3s) → Slow Push-In to Close-Up (4s) → Hold Close-Up (2-3s) → Medium Shot (2s)
```

### Educational Segment
```
Wide Shot (3s) → Medium Shot (3s) → Insert Shot (2-3s) → Wide Shot (3s)
```

### Musical Number
```
Wide Group Shot (4s) → Medium Shot singer (3s) → Medium Shot reaction (2s) → Wide Group Shot (4s)
```

## Quality Checklist

| Check | Requirement |
|-------|-------------|
| Camera is steady | No shake or handheld feel |
| Shot size fits story need | Right shot for right moment |
| Duration suits preschool pacing | Shots held long enough |
| Transitions are gentle | Dissolves and fades only |
| Close-ups are earned | Only for emotional importance |
| Inserts are motivated | Show what children need to see |
| Camera height is appropriate | Default: character eye level |
| No disorienting moves | No whip, crash, or Dutch angles |
